The `preview` tool (server `plugin-previews`) hands the user something to LOOK AT or COPY, wherever they are (phone or desktop, terminal mode or Pretty mode): it lands in their Previews list with a badge and opens in the app. Pass `paths` (files inside this project: png/jpg/gif/webp/svg images, pdf, html, md, txt, csv, json; up to 20) and/or `text` (a string they will copy: a URL, a command, a token, a snippet; up to 64 KB). Add a short `title` and a one-line `note` for context. Use it for screenshots, rendered pages, reports, HTML artifacts, and for any text the user must copy exactly: in terminal mode they cannot select text. Prefer it over describing a picture or dictating a long string.

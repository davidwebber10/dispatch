# Dispatch v3.1.1 — paste screenshots into Chat, and a box that grows

The Chat box now works like the Control Plane and Pretty thread boxes: you can paste or drop
screenshots, the box grows as you type, and your draft stays after a reload.

## The change

- **Paste a screenshot.** Paste an image from the clipboard into the Chat box and it is
  attached. Before, you had to save the image to a file and use the attach button. Pasting
  text works as before.
- **Drop an image.** Drag an image onto the Chat box to attach it. The box shows a cue while
  you drag.
- **The box grows.** The Chat box grows with your text up to about 10 lines, then scrolls.
  It gets small again after you send. Before, it showed only 2 lines.
- **Your draft is kept.** Text you have not sent stays in the box after a page reload.

Not in this release: attaching files that are not images.

## Updating

Web app. Run `dispatch update`, then reload the page.

# Dispatch v4.9.1: long text stays inside the Ledger card

## The fix

- **Long links and names now wrap inside Ledger cards.** A long address with no spaces (like an
  sftp:// link) used to push past the edge of the card, so the card scrolled sideways. Long text now
  wraps inside the card, its chips, the chip popover and the source panel, on desktop and phone.
- **The "Recommended" tag keeps its shape** and no longer breaks mid-word in a narrow card.
- **Tables in the source panel stay readable** instead of squeezing columns down to a few letters.

## Updating

Web only: run `dispatch update`, then reload the app.

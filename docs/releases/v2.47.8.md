# Dispatch v2.47.8 — agents can no longer kill other agents by name or pattern

Pretty and Control Plane Claude agents now refuse commands that stop processes by name or
pattern. (PR #80.)

## What was wrong

Every Claude agent that Dispatch runs has its prompt in its command line. An agent that stopped
its own loop with `pkill -f until` matched every agent whose prompt contains the word "until",
and 14 agent threads stopped at the same time.

## The change

Dispatch now refuses these commands in Pretty and Control Plane Claude threads:

- `pkill` and `killall`;
- `kill` or `xargs kill` fed by `pgrep`, `pidof` or `ps`;
- `kill -1` and `kill 0`.

The agent gets a message that tells it to kill by process id (PID) instead. Kills by PID still
work. CLI threads and Codex threads are not covered, because their commands do not pass through
Dispatch's permission check.

## Updating

Server only. Run `dispatch update`.

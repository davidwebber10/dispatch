# Dispatch v3.0.1 — log in to Claude from Chat

When Chat cannot reach Claude because the login expired, you can now log in again from Chat.
Your message also shows at once when you send it.

## The change

- **Log in to Claude from Chat.** When a Chat reply fails on the Claude login (for example
  "OAuth session expired"), the error box shows **Log in to Claude**. Click it, open the
  Claude login page, sign in, and paste the code that Claude shows. Dispatch saves the login
  and sends your message again. The new login also works for every Claude Code thread on that
  machine, with no restart.
- **Your message shows at once.** Before, Chat showed only "Working…" until it finished
  reading its older summaries, which could take up to 30 seconds. Now your message appears in
  the chat as soon as you send it.
- **Cleaner history.** Claude Code's own error notices (an expired login, a usage limit) no
  longer go into the chat history as a reply from Dispatch. The error box shows them instead.
- **Summaries catch up.** After a login, the summaries that failed on the old login run again
  at once.

## Updating

Daemon and web app. Run `dispatch update`, then reload the page.

# Dispatch v4.5.3 — no "Needs you" box on the project list

## The change

- **The "Needs you" box is gone from the project list**, on the phone and on the desktop.
- **You can still find the threads that wait for you:**
  - The **Status → Needs you** filter in the thread list.
  - **Next thread that needs you** in the command palette (Cmd+K).
  - **Alt+N** on the desktop.
  - The thread's alerts and its status mark.

## Updating

Web only: run `dispatch update`, then reload the app.

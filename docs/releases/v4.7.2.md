# Dispatch v4.7.2 — Chat gets every tool a thread gets

## The change

- **Chat now has your Dispatch integrations and Doppler.** Before, Chat had your own Claude servers
  and Claude connectors, but none of the integrations from Settings → Integrations, for example
  Google Chat, Atlassian, Supermetrics or Fivetran. Threads had them; Chat did not.
- **A new or changed integration applies at the next Chat message.** Dispatch writes Chat's tool
  list fresh for each turn that you start.
- **Turns that answer a thread's report do not change.** For safety, they still get only Chat's own
  memory and thread tools, because a report can contain text from a web page.

## Updating

Needs a daemon rebuild and restart: run `dispatch update`.

# Dispatch v3.1.2: no double sends, images open full size, and test runs that can't freeze the Mac

Fixes to the Chat box from v3.1.1, a full-size viewer for Chat images, and a memory cap on test runs.

## The change

- **No more double sends.** The Chat box now clears the moment you send. Before, it cleared
  only after the send finished, so typing in that gap could send part of a message and then
  send it again. If a send fails, your text comes back in the box.
- **Send stays Send.** The Send button stays greyed for a moment after a send, so a quick
  second tap can't land on Stop and cancel the reply.
- **A failed send after you leave Chat keeps your text.** The text is saved to your draft
  instead of being lost.
- **Dropping text works.** Dragging plain text onto the Chat box inserts it again. In v3.1.1
  the drop was swallowed.
- **Chat images open full size.** Click or tap an image in Chat to open it in the same viewer
  Pretty mode uses. Press Escape or tap outside to close it. Images open from the keyboard too,
  and Tab stays inside the viewer while it is open.
- **Test runs can't use up the Mac's memory.** Test runs use at most half the CPU cores, and
  each test worker is capped at 1.5 GB, so a runaway run fails instead of freezing the machine.
  Agents are now told not to start overlapping full test runs or cut their output short.

Known gaps, for a follow-up release:
- A picture inside a link takes two Tab stops, and clicking it can follow the link.
- An image in an AI reply closes its viewer when the reply finishes.
- If a send fails after you leave Chat, attached images are dropped without a warning.
- Not yet tested on an iPhone.

## Updating

Web app and core. Run `dispatch update`, then reload the page.

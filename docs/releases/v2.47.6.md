# Dispatch v2.47.6 — Codex replies in Pretty no longer go missing

In a Codex thread in Pretty mode, a reply could fail to show: the tool rows and the cost line
appeared, but the reply text did not until a page reload. (PR #77.)

## The change

When Codex finishes a message, Dispatch now sends the message's whole text as well as the
streamed pieces. The Pretty view uses it to fill in or add a reply that it missed. A reply shows
once, also when the history page loads at the same time, and the history above it stays.

## What was wrong

Pretty drew a Codex reply only from its streamed pieces, and nothing sent the whole text again.
A view that missed the start of a reply dropped all of its pieces. Two ways to miss it:

- you left the thread while a reply streamed and came back before it ended;
- the live connection dropped while a reply streamed.

## Updating

Server and web app. Run `dispatch update`, then reload the page.

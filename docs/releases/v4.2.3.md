# Dispatch v4.2.3 — drag the message box to the size you want

## The change

- On a phone, in the CLI view, the line at the top of a long message box is now a real drag
  handle: drag it down to shrink the box, up to grow it, and it stays where you let go. A tap no
  longer switches it between two sizes. It never goes below two lines or above the text's own
  height.

## Updating

Web client only. Run `dispatch update` (or `./bin/dispatch update` from the repository folder),
then reload the app.

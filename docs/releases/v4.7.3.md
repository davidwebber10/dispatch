# Dispatch v4.7.3 — swipe to archive asks first

## The change

- **A swipe to archive in the Threads list on the phone now asks "Archive thread?"** before it
  archives. Before, the thread was archived at once. A swipe in a project's thread list already
  asked first; now both lists work the same way.
- **Cancel** keeps the thread. **Archive** archives it, and you can restore it later from the
  archive.

## Updating

Web only: run `dispatch update`, then reload the app.

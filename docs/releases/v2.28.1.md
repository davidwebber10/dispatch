# Dispatch v2.28.1 — fresher open-weights models in the opencode picker

The OpenCode harness curates a short list of the strongest open-weights
models, driven through OpenRouter. Two of them had fallen a version behind:
GLM and Qwen. Both are now on their current flagship.

## The change

In the OpenCode model picker:

- **GLM-5.2 → GLM-5.3** (`openrouter/z-ai/glm-5.3`). This is also the new
  default model for an OpenCode thread created with no pick, so a fresh
  thread lands on the current GLM rather than the one it replaced.
- **Qwen3.7 Max → Qwen3.8 Max** (`openrouter/qwen/qwen3.8-max`).

Kimi K3, DeepSeek V4 Pro, and MiniMax M3 are unchanged.

## Updating

Web-only for the picker list; a browser refresh is enough to see the new
options. Threads that pick the default get GLM-5.3 on their next spawn, which
needs a daemon rebuild/restart (`dispatch update`) to pick up the new default.

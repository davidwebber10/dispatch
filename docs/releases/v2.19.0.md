# Dispatch v2.19.0 — the icon rail, and a Files picker that can search

## The change

The desktop shell has a new spine: a **full-height icon rail** on the far left replaces
the old top bar. Threads, Board and Analytics are vertical items with icons and labels;
the active view gets an accent bar, editor-style. Everything the top bar held survived
the move — the Dispatch logo is now the rail's top button and opens the server switcher
(with the daemon version) to the side, and the panel toggles, connection dot, server
label and Settings gear live at the rail's foot. The content area gets the 40px back.

The **Files picker was rebuilt**:

- **Search all files.** Typing in the filter searches the *entire repository* — a
  `git ls-files` index, so `.gitignore` is respected — not just the folders you had
  expanded. Matches are ranked (basename hits first) and the matched characters are
  highlighted in the results.
- **Changed mode.** A second tab lists every uncommitted file with its git status
  letter (M/A/D/R/?); the same letters annotate rows in the tree, and the Inspector's
  Files tab wears a yellow badge with the count.
- **A branch chip** in the header shows the working dir's current branch.
- **Dotfiles are hidden by default**, with a `·*` toggle that persists. A collapse-all
  button folds the tree.
- File rows show their **size**.

Selection, Shift/Cmd ranges, the right-click menu (Save As, Copy Image, Copy Path,
Reveal, Rename, Delete) and open-in-tab all behave exactly as before, on desktop and
mobile.

## Under the hood

- Three additions to core: `GET /git/status` (branch + porcelain `-z` changes),
  `GET /files/flat` (recursive listing with a bounded fs-walk fallback for non-git
  dirs), and sizes in the directory listing.
- A ranked fuzzy matcher (`lib/fuzzy`) returns match indices, so highlighting is exact
  rather than a re-scan.
- ~20 new tests across the porcelain parser, the matcher, and the pane's new modes.

## Updating

Needs a **daemon rebuild and restart** — the git-status and search endpoints are in
core. Hard-refresh the browser afterwards; the shell layout changed. Until the daemon
restarts, the new UI degrades quietly: no branch chip, an empty Changed tab, and search
finds nothing.

# Dispatch v4.1.0 — a redesigned Settings

## At a glance

- **Every Settings page is redesigned.** Calm grouped cards, one-line hints, and a page of its own
  for each item that has more than a switch.
- **Desktop dialogs are dialogs.** Pickers and Add forms open centered on a computer; the phone
  keeps its slide-up sheets.
- **New previews are easy to spot.** In a thread on the phone, ⋯ shows a dot and the Previews row
  shows how many are new.
- **Fixes** for blank preview images and for zoomed pictures hiding under the viewer's top bar.

## Settings

- **One layout everywhere.** Each page opens with a short line about what it is for, then labeled
  cards of rows. Small controls sit on the right; wide ones sit under their label. Dangerous
  actions are last, in red.
- **Pages for items.** Accounts, agent harnesses (Claude Code, Codex, Grok, OpenCode),
  integrations, signed-in devices and skills each open their own page, with the item's name in
  the header. The lists stay short.
- **Agents** fits on one phone screen; each harness's defaults are on its own page, and
  OpenCode's model list lives there too.
- **Usage limits** shows a card per account with a bar for each limit.
- **Appearance**: the theme picker opens from one row, and the accent colors sit in one row.
- **Safer:** removing an integration, a server or a skill, deleting a secret, disconnecting
  Doppler, and revoking a device or its alerts now ask first.
- **Tools** lists each tool with its state (Installed, Sign in needed, Missing).
- **About & updates** puts the version, Check for updates and the release notes together, with
  links to the release history and docs.

## Elsewhere

- **⋯ in a thread (phone):** a dot when the thread's project has new previews, and a count on the
  Previews row.
- **Previews:** images inside the thread's Previews sheet load again (they showed as blank squares
  on iPhone).
- **File viewer:** a zoomed picture can be moved until its top and bottom edges clear the top bar
  and the strip of files.
- **For plugin authors:** a thread menu item can show a live count (`badge`), and plugins can use
  the shared settings controls (`d.ui.SettingsGroup`, `SettingsRow`, `Segmented`, `MultiSelect`).

## Updating

Web client only. Run `dispatch update` (or `./bin/dispatch update` from the repository folder),
then reload the app. On a phone, close and reopen the app if it still looks old.

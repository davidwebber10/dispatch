# Dispatch v3.16.1 — the update shows the version it installs

## The change

When a second release came out after Dispatch last looked, Settings and the update prompt still
showed the earlier version and its notes, although Update installed the newest one. Now:

- Pressing Update asks GitHub again first, so the version and notes you see are the ones being
  installed.
- Opening Settings → Updates refreshes what it shows.
- Dispatch looks for new releases every 15 minutes (was 45).
- "Check for updates" no longer clears the release notes when nothing newer is out.

## Updating

Run `dispatch update`, then reload the app on each phone. There is no database migration.

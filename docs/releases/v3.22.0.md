# Dispatch v3.22.0: add an account from the New Thread modal

## The change

- **New Thread → Account, always.** A Claude Code or Codex thread shows the Account row as
  soon as the daemon has accounts, even when the only account is the CLI's own login.
- **Add account… in that row.** The last option opens a small panel under the row.
  - Claude: name the account (optional), then the same login as Settings → Accounts: open
    the page, paste the code. When it finishes, the new account is picked for the thread you
    are about to start.
  - Codex: name the account, then "Open the sign-in thread". The account gets its folder and
    a "Sign in — Codex" thread opens for it. Finish the login there, then start a thread on
    the new account.
- A thread still pins its account only when the harness has more than one.

## Updating

Web client only. Run `dispatch update` (or `./bin/dispatch update` from the repository
folder), then reload the app.

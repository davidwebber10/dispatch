# Dispatch v4.7.8 — text goes back to normal size after you rotate the phone

## The fix

- **On iPhone, the text no longer stays big after you rotate.** If you turned the phone to landscape
  in a thread and then back to portrait, the text stayed enlarged and stretched, and you could not move
  around the app until you closed it. The app now tells iOS not to resize its text on rotation, so the
  page looks the same in portrait as it did before you rotated.

## Updating

Web only: run `dispatch update`, then reload the app.

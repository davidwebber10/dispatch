# Dispatch v3.18.0 — choose the words Claude shows while it works

## The change

Settings → Harnesses → Claude Code has a new **Working words** option for the words Claude shows
while it works, such as "Flibbertigibbeting…".

- **Claude's own** (the default) keeps Claude's words. **Add to Claude's** mixes yours in.
  **Only mine** shows only yours.
- Type your own, separated by commas, or start from a set: Plain, Dispatch, Workshop, Kitchen,
  POLYWOOD or Space.
- **Your own sets:** "Save these words as a set" keeps the list under a name, next to the built-in
  sets. Tap × on a set to delete it.
- CLI threads use the words when they start or restart. Pretty threads, Control Plane and Chat
  use them for their "Working…" line, one word per turn.

## Updating

Run `dispatch update`, then reload the app on each phone. There is no database migration.

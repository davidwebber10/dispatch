# Dispatch v4.11.3 — an enlarged photo stays open

## The change

- **An enlarged photo in a Pretty thread stays open while the thread writes.** Before, a new line of
  the assistant closed the photo, for example a screenshot that a tool returned. The photo viewer now
  sits above the chat rows, the same as in Chat, so a new line no longer closes it.
- **Project in the new-thread dialog sits below the tool picker** (Claude Code, Codex, Grok…), as a
  row like Mode, Account and Model.
- An opened tool call already stayed open while new lines arrived. That does not change.

## Updating

Web only: run `dispatch update`, then reload the app.

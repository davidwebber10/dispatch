# Dispatch v3.24.3: a quieter thread header on the phone

## The change

- **Under the thread name, the phone shows only the status dot and the account.** The project
  name and the "Pretty" / "CLI" label are gone. The Back button already names the project, and
  the thread body shows which mode it runs in. The "Switch to Pretty" / "Switch to CLI" row in
  the ⋯ menu is unchanged.

## Updating

Web client only. Run `dispatch update` (or `./bin/dispatch update` from the repository folder),
then reload the app.

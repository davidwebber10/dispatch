# Dispatch v3.15.0 — fast launch on any network

## The change

The app now opens straight away, even on a weak signal or while the phone's VPN (Tailscale) is
still waking up. Measured on a phone-sized screen with a slowed CPU and network:

| | Before | Now |
|---|---|---|
| First launch, 4G-like | blank for 3.9 s | content at 0.8 s |
| Reopen, slow network | blank 3.1 s, projects at 6.3 s | projects at 0.16 s |
| Reopen while the network stalls | blank for 12 s or more | projects at 0.16 s |
| Back from the background | reconnects and reloads every thread | carries on where it was |

- **No black or white screen.** The app shows its saved copy immediately instead of waiting for
  the Mac, and refreshes it in the background. The page is dark from the first frame.
- **Your projects and threads appear at once.** The last lists are kept on the device and shown
  at launch; the live lists replace them the moment the Mac answers.
- **No "Reconnecting" on every return.** Coming back, the app checks whether the connection is
  still alive and keeps it if so, so threads don't reload and spin. The status only shows when the
  connection has really been down for more than 1.5 seconds, and the first connect says
  "Connecting…".
- **Smaller download after an update.** The app's main code is compressed (2.7 MB → about 340 KB)
  and cached for good. The file editor, notes editor, terminal and QR code load only when you use
  them (the terminal loads in the background once the app is idle). Fonts now come with the app
  instead of from Google.

## Known limits

The first launch after updating still waits for the Mac once, since the previous version had no
saved copy to show. Launches after that are fast. The numbers above are from a simulated phone,
not a real iPhone over Tailscale.

## Updating

Run `dispatch update`, then open the app on each phone once. There is no database migration.

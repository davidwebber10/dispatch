# Dispatch v3.10.4: see and sign out each device, plus a security sweep

## Signed-in devices

- **A list of signed-in devices.** Settings > Access now lists each browser and phone that
  signed in with a code or QR, with when it was last seen. You can rename a device.
- **Sign out one device.** Each device has its own Revoke button. `dispatch access rotate`
  still signs out every device at once.
- **Nobody is signed out by this update.** A browser that was already signed in is added to
  the list the first time it is used. A button signs out any older sign-in not in the list.
- **The QR code works from the Mac.** When you open Settings > Access on the Mac itself, the
  phone address is filled in with the Mac's Tailscale or Wi-Fi address instead of
  `localhost`. You can still type a different address.
- Phones on your own Tailscale account do not need to sign in, so they do not show in the
  list. A note in Settings > Access says so. Manage those in Tailscale.

## Security

- **Stopping a thread stops its programs.** Programs a thread started get a stop signal, then
  are force-stopped after 3 seconds. Programs that were started to run on their own in the
  background may still keep running. `docs/security.md` explains this.
- **Git hooks in a project folder no longer run.** Dispatch turns off git's fsmonitor setting
  when it reads a project's git status.
- **Unsafe links are blocked.** `javascript:`, `data:` and `vbscript:` links are refused in
  the Browser tab and in image downloads. Normal images still download.
- **Fewer path leaks.** Update and start errors no longer show folder paths.

## Under the hood

- PR #119 (device list) and PR #120 (security sweep). Codex reviewed both.
- The device list was tested on an iPhone over Wi-Fi with a spare copy. It was not tested on
  WSL2. The `javascript:` block was tested in Chrome only.

## Updating

Run `dispatch update` (or `./bin/dispatch update` from the repository folder), then reload the
app on each phone. This release adds a database migration (014), which runs on restart.

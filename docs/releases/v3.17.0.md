# Dispatch v3.17.0 — one conversation view for threads, Control Plane and Chat

## The change

Chat now draws its conversation with the same view as Pretty threads and Control Plane, so all
three read alike. Dispatch had three separate renderers; it now has one.

What you'll notice in Chat:

- **Tool calls** use the thread style: one line with the tool, a short summary of what it ran and a
  line count; tap to see the input and output, with syntax highlighting. Several calls of the same
  tool in a row fold into one line ("Bash ×3").
- **Turns** are separated by a hairline, and back-to-back messages from you share one "YOU" label.
- **Images you attach** show as their own pictures under your message.
- Chat's own pieces are unchanged: the "recalled" lines, Started cards for threads it opens, thread
  report cards, doc chips, project labels, file chips, and search jumping to a message.
- A tool call that was cut off before it logged a result shows as finished with no output.

## Updating

Run `dispatch update`, then reload the app on each phone. There is no database migration.

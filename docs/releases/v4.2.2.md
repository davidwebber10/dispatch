# Dispatch v4.2.2 — the Plugins list says which plugin has something new

## The change

- On a phone, the Plugins tab's dot now has a reason you can see: each plugin in the list shows
  its own count of new items (for example Previews you have not opened, or a new Coach tip).

## Updating

Web client only. Run `dispatch update` (or `./bin/dispatch update` from the repository folder),
then reload the app.

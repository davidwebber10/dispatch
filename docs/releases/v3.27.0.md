# Dispatch v3.27.0: a full-screen file viewer, and a dot on Settings when an update waits

## The changes

- **A full-screen file viewer for previews and chat images.** Tap any file of a preview and it
  opens in a viewer on all of that preview's files. On a phone, swipe sideways to the next
  file, pinch to zoom around your fingers, double-tap a spot to zoom into it, drag a zoomed
  picture inside its edges, and pull down to close. On a desktop, the arrows and the arrow
  keys step through, the wheel zooms around the cursor, + / − / 0 and the toolbar buttons
  zoom, and a zoomed picture drags with the mouse. A strip of thumbnails at the bottom jumps
  to any file. Markdown and text files render in place with Copy; a pdf or an html page shows
  in a frame with Open for the browser's own viewer. Copy, Share (a phone's share sheet, so a
  screenshot can go to Photos) and Download sit in the top bar. Chat images and markdown images
  open the same viewer, so every picture in the app gets the same gestures.
- **A dot on Settings while an update waits.** The phone's Settings tab and the desktop rail's
  Settings item carry a plain dot (no number) when a newer Dispatch is available. A banner at the
  top of Settings, on every section, names the version and the one running, links the release
  notes, and has an Update now button. Dismissing the update window does not clear them, so
  Settings is always a place to find the update.

## Updating

Web client only. Run `dispatch update` (or `./bin/dispatch update` from the repository folder),
then reload the app.

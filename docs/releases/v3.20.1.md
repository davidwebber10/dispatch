# Dispatch v3.20.1: a usage ring per tool

## The change

- **The usage chip shows every tool.** The "wk 12" text in the desktop rail showed one tool
  only. It is now one ring per tool, stacked, with the tool's mark in the middle: Claude,
  Codex, and any other tool that reports. Each ring fills with the window closest to its
  limit, green, then yellow, then red. A paused tool's ring is red. The whole stack is one
  button and opens the Usage sheet.
- **The phone header does the same**, with the rings in a row.
- Hover a ring on desktop for every window's figure, or the chip for all tools at once.

## Updating

Web only. Run `dispatch update` (or `./bin/dispatch update` from the repository folder),
then reload the app.

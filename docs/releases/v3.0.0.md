# Dispatch v3.0.0 — Chat

Dispatch 3 adds **Chat**: one conversation that never ends. You talk to Dispatch in one place.
It remembers what you discussed, across all your projects, and it does the work itself or
starts threads and reports back when they finish. Threads, projects and the Control Plane
work as before.

## Chat

- **One chat, no threads to manage.** Open **Chat** (the second icon in the left rail; a tab
  on the phone). Ask a question or give a job. Dispatch answers, runs tools, or starts a
  thread in the right project.
- **It remembers.** Older messages become short summary lines that Dispatch can open again
  when it needs the detail. So it can use months of history without a long, slow context.
  A short line under a reply ("recalled") shows when it looked back.
- **All your projects.** Dispatch knows your projects, their open items, and their threads.
  To point at one project, tap the projects button left of the attach button. The project
  shows as a pill above the message box and clears after you send. When you do not pick a
  project, Dispatch works out the project from what you say.
- **Threads report back.** A thread that Chat starts sends one report into the chat when it
  finishes or when it needs you. Your messages in such a thread show "VIA CHAT". The
  Control Plane does not get reports from these threads.
- **Search the memory.** The search box at the top of Chat finds any message, also the
  oldest ones, and jumps to it. **Back to latest** returns to the end.
- **See and steer the memory.** The memory view shows the summary lines that Dispatch reads.
  **Chat instructions** (in the memory view) are standing notes that Dispatch reads on each
  reply, for example "I work on POLYWOOD; keep answers short".
- **Projects panel.** A side column (a sheet on the phone) shows each project with its live
  threads, the threads that need you, and the last report. **Refresh** reloads it.
- **Stop.** While Dispatch replies, the send button becomes **Stop**. Stop ends the reply.
  What Dispatch already wrote stays. If you type during a reply, the button is **Send**, and
  the running reply reads your message.
- **A first start with history.** When the daemon first starts on 3.0.0, Chat imports the
  memory notes and open items of your projects, so it does not start empty.

## Requirements for Chat

Chat uses the Claude Code CLI (`claude`): **Opus** writes the replies and **Haiku** writes the
summaries. Your Claude login must have access to both. Chat works in `~/.dispatch/chat` and
loads your normal Claude Code MCP servers and skills. The other harnesses do not change.

## Other changes

- **Project order stays put.** With "Most recent" sort, two busy projects no longer swap
  places on each update. The order changes when you reload, add a project, change the sort,
  or come back to the tab.
- **Open source.** Dispatch is now under the MIT license.
- **Docs.** The README describes Chat, Windows (WSL2) setup, and all four harnesses.
  `docs/providers.md` has a new OpenCode section.

## Updating

Daemon and web app. Run `dispatch update`, then reload the page. On its first start, the
daemon imports your project notes into Chat; this takes a few seconds.

# Dispatch v4.5.2 — the Previews dot is back on ⋯

## The change

- **The dot on a thread's ⋯ button is back.** It shows when the thread has a preview that you
  have not opened yet. v4.5.0 removed it by mistake.
- **The count shows where you open the previews.** The Previews row in the phone's thread menu
  and the Previews tab in the desktop right column show the number of new previews.
- **The count is for this thread only.** A preview from another thread in the same project no
  longer adds to the dot.

## What was wrong

In v4.5.0 the "Project previews" row left the thread menu, and the thread's own Previews tab took
its place. That row was the only thing that set the dot on ⋯, so the dot was gone.

## For plugin authors

A right-column tab (`inspectorTabs`) can now have a `badge`: `{ subscribe, get({ terminalId, sessionId }) }`.
The count shows on the tab and on its phone menu row, and it adds to the thread's ⋯ dot.

## Updating

Web only: run `dispatch update`, then reload the app.

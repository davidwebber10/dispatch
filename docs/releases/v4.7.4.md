# Dispatch v4.7.4 — thread links in Chat, usage in the account switcher, a better empty Inbox

## Thread links in Chat

- **When Chat names a thread, it links it.** A tap opens that thread in Projects / Threads, on the
  desktop and on the phone. Ask Chat "where did I talk about X?" and tap the answer.
- A link to a thread's address (`/p/<project>/t/<thread>`) opens that thread from any reply, also
  in a thread. It never opens a new browser tab.

## Usage in the account switcher

- **Switch account** shows each account's usage ring, the same ring as in the left rail. You can
  see at once which account has room left before you switch.

## The empty Inbox

- An empty Inbox now shows a tray icon, a short title and one line of help, centred. This applies to
  the thread's Inbox tab, a project's Inbox, and the Inbox screen.

## Updating

Needs a daemon rebuild and restart (Chat's prompt changed): run `dispatch update`, then reload the
app.

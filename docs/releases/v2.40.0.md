# Dispatch v2.40.0 — copy and paste on Windows, scratch files, and CSV cell selection

Fixes from Jordan Adams's WSL2 onboarding report (issue #49). (PRs #50, #51, #52.)

## The change

- **Terminal copy and paste on Windows and Linux.** With text selected, Ctrl+C copies it and
  clears the selection. With no selection, Ctrl+C still interrupts the program. Ctrl+V pastes.
  Macs keep Cmd+C and Cmd+V as before.
  - Ctrl+V no longer sends a literal ^V to the program, so vim block mode and nano lose that
    key. Windows Terminal and VS Code work the same way.
- **Untracked folders in the Changed tab.** The Changed tab now lists each file in a new,
  untracked folder. Before, it showed the folder as one row, and a click opened an empty editor.
- **Ignored scratch files are searchable.** Search now finds files in a gitignored folder, for
  example a `scratchpad/` in `.git/info/exclude`. Search skips `venv`, `.venv`, `target`, and
  `coverage` folders, so they cannot fill the index.
- **Failed reads and saves are visible.** When a file cannot be read, the editor shows the
  reason and a Retry button. It no longer shows an empty file that you can edit and save. A
  failed save shows an alert with the reason.
- **Cell selection in the CSV table.** Click a cell to select it. Shift-click or drag to
  select a rectangle. Ctrl+C (Cmd+C on a Mac) copies the rectangle as TSV, which pastes into
  Excel and Sheets as cells. The arrow keys move the selection, Shift+arrow extends it, Enter
  edits the cell, and Escape clears the selection.

## What was wrong

- **Cmd+S could empty a file.** On a file that failed to load, Cmd+S (or Ctrl+S) wrote the
  empty editor to disk, so a short network error could empty a real file. Cmd+S now does
  nothing on a tab with no unsaved changes.
- **Error messages had no reason.** They said only `failed: 404`. They now include the
  server's reason, for example `ENOENT` or a refused path.

## Updating

Needs a daemon rebuild and restart: run `dispatch update`. The Changed tab and search fixes
are in the daemon. The terminal, editor, and CSV changes are in the web app.

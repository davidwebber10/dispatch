# Dispatch v3.9.0: Previews, and a Threads view on the phone

## The change

- **Previews: a thread shows you files and text.** Every thread has a new `preview` tool. It
  can hand you images, PDFs, HTML pages, Markdown, text, CSV and JSON files from the project,
  and a string to copy. On the phone, a **Previews** key sits left of **esc** above the
  terminal composer, and a **Previews** button sits in the project header. Both open a sheet
  with the project's previews. On desktop, **Previews** in the left rail shows the full history
  across projects, with the project, thread and time for each. A badge counts what you have
  not seen.
- **Copy from a terminal thread.** A string a thread hands you shows in a box with one
  **Copy** button. No more switching to Pretty mode to copy a line.
- **Images open in the lightbox.** Markdown, text, CSV and JSON open in the app with Copy.
  PDF and HTML open in a new tab in the browser's viewer.
- **`post_image` lands in Previews too**, so a terminal-mode thread's screenshot reaches you.
- **Threads view on the phone.** The Projects tab has a Projects ⇄ Threads switch. Threads
  lists every thread of every project, newest activity first, with project filter chips and
  the search box. The Pinned tab, the pin icon and the Pin thread menu entry are gone.

## Under the hood

- `POST /api/sessions/:id/previews` (a thread may post where it may read), list, seen and
  delete routes, and a file route that re-checks the project folder and serves HTML with a
  sandbox policy (no cookie, no app API). Events `preview:new` and `preview:changed`.
- Spec: `docs/superpowers/specs/2026-10-28-previews-design.md`.
- Tests: the routes, the DB module, the MCP tool, the store, the item, the all-threads view.

## Updating

Needs a daemon rebuild and restart. Run `dispatch update` (or `./bin/dispatch update` from
the repository folder), then reload the app. Threads that are already running get the new tool
when they restart.

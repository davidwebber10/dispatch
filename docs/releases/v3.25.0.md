# Dispatch v3.25.0: a filter sheet for the phone's thread list

## The changes

- **Filters open as a sheet with folded sections.** On the phone's Threads view, the Filters
  button opens a bottom sheet. Each filter is a section that opens and closes with a tap, and
  its header names the current pick. Open, a section lists its choices with a count each,
  sorted by count. The sheet scrolls, so a few dozen projects no longer wrap into a wall of
  pills.
- **Three new filters: Account, Harness, Model.** Account lists the accounts that threads run
  on (it appears once the daemon reports accounts). Harness lists the thread types in use
  (Claude Code, Codex, Terminal, ...). Model lists the models threads were started with, and
  "Default" for threads that use the harness default.
- **Faceted counts.** A choice counts the threads that match the search and every other
  filter, so a pick never leads to an empty list. The picks are remembered per device, as the
  project pick was.
- **Banked Codex resets.** The Usage sheet still lists how many resets are banked and when each
  expires. "Use" now opens the ChatGPT usage page, because Codex's own app-server refuses the
  in-app spend ("nothing to reset") until a limit is hit.

## Updating

Web client only. Run `dispatch update` (or `./bin/dispatch update` from the repository folder),
then reload the app.

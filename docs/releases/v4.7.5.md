# Dispatch v4.7.5 — the usage rail keeps its order

## The change

- **One fixed order.** The usage rings in the left rail and the cards in the Usage flyout always
  list the accounts in the same order. Opening a thread no longer moves its account to the top.
- **A sliding highlight.** A green box with "THIS THREAD" marks the open thread's account. When you
  open a thread on another account, the box slides to that account's ring, and the rings stay where
  they are. A device that asks for less motion gets a jump instead of a slide.
- **Less text at the bottom of the rail.** The connection dot and the server name ("LOCAL") are
  gone. The app still shows its notice when the connection drops.

## Updating

Web only: run `dispatch update`, then reload the app.

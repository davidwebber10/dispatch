# Dispatch v4.7.7 — Thread details has the same actions as the menu

## The change

- **The thread's actions look the same everywhere.** The desktop right column (the Details tab) and
  the phone's Thread details now show the thread menu's own buttons and list: Rename, Branch,
  Account and Alerts, then Download thread, Copy thread ID, Reload thread, Reset status, "Why is this
  thread in this state?" and Auto-archive…, and Archive thread at the end.
- The old row of plain buttons (Reload Thread, Reset Status, Switch Account, Archive Thread) is gone.
- Inside Thread details, the list has no "Thread details" row, so it never links to itself.

## Updating

Web only: run `dispatch update`, then reload the app.

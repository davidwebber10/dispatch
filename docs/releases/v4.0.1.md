# Dispatch v4.0.1 — a smoother fade on long thread names

## The change

- On the phone, a long thread name in the header fades at its edges while it scrolls. The fades
  now fade in and out smoothly instead of switching on and off.

## Updating

Web client only. Run `dispatch update` (or `./bin/dispatch update` from the repository folder),
then reload the app.

# Dispatch v3.3.0: doc links everywhere, closable sheets, every thread report

## The changes

- **Doc links in every structured thread (#96).** A link to a `.md` or `.txt` file in any
  structured thread, whatever the harness (Claude, Codex and others), opens the read-only doc
  viewer instead of sending the page away. Absolute paths, relative paths, `file://` links and
  `:line` or `#L` suffixes all work. Bare doc paths become chips. Web and email links open in a
  new tab. Other links do nothing, rather than reloading Dispatch.
- **Mobile sheets always close (#97).** The Projects panel and other bottom sheets on the phone
  now close with a drag down past a quarter of their height, a flick, or a 44pt X button. The
  list inside still scrolls. Tested on iPhone.
- **Every thread report reaches Chat (#98).** Chat used to hear only a thread's first report
  after it was started or messaged. Later turns, errors and questions were dropped, so a
  thread could wait for you for over an hour unseen. Chat now gets a report at every turn end,
  error and question, with identical reports deduplicated.
- **A chat reply answers a pending question card (#82, by @jadams-pw).** When a structured
  thread asks a question with a card, typing a reply in the thread now answers it. The
  question ID survives compaction, Dismiss and Discuss no longer leave a stuck card, and a
  quick Discuss then Submit no longer races.
- **Terminal replay stops re-answering old queries (#84, by @jadams-pw, fixes #83).** Reopening
  a terminal no longer sends stale replies to colour, cursor and device queries that were
  already answered, which showed up as junk text in Codex and other TUIs.

Known limits:
- Doc links: a long-press on the phone shows `#`; relative links resolve against the project
  folder, not the thread's working folder; an open doc reappears when the thread is reopened;
  a streaming reply still reloads links. Not yet clicked in the iPhone app.
- Thread reports: messages queued mid-turn are not reported on their own, and Chat wakes more
  often than before.
- Terminal replay: a query still pending when replay ends is not answered.
- The doc-read folder swap race stays tracked in #94.

## Updating

Daemon and web app. Run `dispatch update`, then fully close and reopen the app (or reload the
page).

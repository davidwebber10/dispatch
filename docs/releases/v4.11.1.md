# Dispatch v4.11.1 — start a thread from the Threads list

## The change

- **A green + right of Filters on the Threads list**, on the desktop and on the phone, the same as
  on the Projects list.
- It opens the normal new-thread dialog, with one more choice at the top: **the project**.
- **The project it starts on:** the project of the thread that is open, if one is open. Otherwise,
  the project with the most recent activity.
- After **Start new thread**, the new thread opens in its project.

## Updating

Web only: run `dispatch update`, then reload the app.

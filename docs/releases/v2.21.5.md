# Dispatch v2.21.5 — a one-line top bar on the phone

## The change

The mobile Projects screen no longer spends two rows on chrome. The app icon,
the search field, sort, and the new-project button now share one line — search
got a little smaller to make room — and the project list gets the freed row.
Board mode and the other bottom tabs are unchanged.

## Updating

**Web-only** — a browser refresh is enough.

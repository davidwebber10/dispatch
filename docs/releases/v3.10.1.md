# Dispatch v3.10.1 — The sign-in banner no longer traps you on the phone

## The fix

- **The sign-in / link banner no longer covers the phone's top bar.** On a phone (seen on an
  iPhone 17e), the "Authentication required" banner sat on top of the header and notch. Its
  Dismiss button could be out of reach, which left you with no way back to Chat, Projects or
  Threads. The banner now sits below the top bar and the notch.
- **Minimize.** A new Minimize button turns the banner into a small pill while a sign-in is
  still pending. Tap the pill to bring the banner back, or dismiss it from the pill.
- **Dismiss is easier to hit and says when it fails.** The buttons are full-size touch targets
  (44 pt). If Dismiss fails, you now see an error and can retry, where before nothing happened.
- **Long links wrap** and the banner body scrolls, so a long sign-in link no longer pushes the
  buttons off screen.
- On desktop the only change is the new Minimize button.

## Under the hood

- `AuthBanner.tsx`: places itself below the mobile header with the safe-area inset, gets a
  scrolling body, a minimized pill state, and Dismiss errors scoped to their own request.
- Tests: 23 banner tests; tested by hand on an iPhone 17e in Safari (banner placement, Dismiss,
  long link, Minimize, Dismiss from the pill). Not tested in the home-screen app.

## Updating

Run `dispatch update` (or `./bin/dispatch update` from the repository folder), then reload the
app on each phone.

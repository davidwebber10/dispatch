# Dispatch v2.21.4 — the file search admits when it's slow

## The change

The Files panel's search no longer sits on a bare "SEARCHING…" with no hint.
Building the search index can genuinely take a while on a big project (the
index walks up to 20,000 files, cold disk included), and a request fired into
a network blip can hang outright. After 15 seconds the heading now says
**"INDEX SLOW OR UNAVAILABLE · STILL TRYING"** — and it means it: the request
is not abandoned, so when the index finally arrives the matches replace the
notice. If it failed, the next keystroke retries.

## Updating

**Web-only** — a browser refresh is enough.

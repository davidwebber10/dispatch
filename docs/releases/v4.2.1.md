# Dispatch v4.2.1 — a full-screen editor for long messages on a phone

## The change

- On a phone, when a message reaches three lines, an expand icon appears at the top right of the
  message box. Tap it to write in a full-screen editor: collapse at the top right, Send at the
  bottom right. The keyboard stays down until you tap the text, so you can read and scroll first.
- In the CLI view, a long message is one box: the drag handle that shrinks it to two lines now sits
  inside the box, with no panel around it.

## Updating

Web client only. Run `dispatch update` (or `./bin/dispatch update` from the repository folder),
then reload the app.

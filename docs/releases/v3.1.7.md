# Dispatch v3.1.7 — the Claude version check uses the full environment

## The change

Nothing changes that you can see. Dispatch reads the Claude Code version to decide how it
gives a thread its instructions: in a private file, or on the command line. That check now
runs with the same full environment as a thread.

## What was wrong

This is the same mistake that v3.1.6 fixed in the sign-in check. The version check ran with
only the extra settings that Dispatch adds for threads, without `USER` or `HOME`. Today's
Claude CLI does not need them to print its version, so nothing broke. A future CLI that does
need them would have made Dispatch silently put instructions back on the command line.

## Under the hood

- New test: the version check keeps the daemon's own environment under the thread settings.

## Updating

Needs a daemon rebuild and restart. Run `dispatch update`. You can also wait for the next
update, because this fixes no visible problem.

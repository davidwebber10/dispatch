# Dispatch v2.29.0 — the OpenCode picker, now every flagship via OpenRouter latest aliases

The OpenCode harness runs models through OpenRouter under your own
OpenCode/OpenRouter credential. Its picker used to carry five curated
open-weights ids, and two of them had already fallen a version behind (the
2.28.1 fix swapped GLM and Qwen by hand). Hand-curating a list that goes stale
every few months is the wrong shape. So the picker is now alias-driven.

## The change

The OpenCode model picker now offers **thirteen** models. Every family that
exposes an OpenRouter **`-latest` alias** uses it, so the picker always
resolves to the current flagship and never falls a version behind again:

- **Claude Opus**, **Claude Fable** — `anthropic/claude-opus-latest`,
  `anthropic/claude-fable-latest`
- **GPT** — `openai/gpt-latest`
- **Gemini Pro**, **Gemini Flash** — `google/gemini-pro-latest`,
  `google/gemini-flash-latest`
- **Grok** — `x-ai/grok-latest`
- **GLM** — `z-ai/glm-latest` (also the new default for a thread created
  with no pick)
- **Kimi** — `moonshotai/kimi-latest`
- **DeepSeek V4** — `deepseek/deepseek-v4-flash-latest`. OpenRouter only
  exposes a `-latest` alias for the Flash tier, so V4 resolves to Flash; if a
  Pro-latest alias appears, that line switches to it.

Four families have no `-latest` alias at all, so they stay pinned to their
current top id (verified against OpenRouter's live catalog):

- **Qwen3.8 Max** — `qwen/qwen3.8-max`
- **MiniMax M3** — `minimax/minimax-m3`
- **Llama 4 Maverick** — `meta-llama/llama-4-maverick` (new — fills the gap
  where the picker had no Meta representative)
- **Mistral Large** — `mistralai/mistral-large` (new — the Mistral family was
  absent entirely)

## Under the hood

- `OPENCODE_DEFAULT_MODEL` moved from the pinned `glm-5.3` to `glm-latest`,
  so a fresh OpenCode thread lands on whatever GLM is current, not the id it
  replaced.
- The pricing test's documented-unpriced list (the models whose real cost
  arrives on the wire as `ACP usage_update.cost`, so a price table here would
  duplicate a number the provider already reports) now covers all thirteen
  picker ids. The `-latest` alias string never matches a price table, so each
  alias needs its own entry.

## Updating

Web-only for the picker list — a browser refresh shows the new options. The
new `glm-latest` default takes effect on the next OpenCode spawn, which needs
a daemon rebuild/restart (`dispatch update`) to pick up the changed constant.

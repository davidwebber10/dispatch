# Dispatch v4.7.6 — Download thread, and a simpler thread menu

## Download thread

- **A new row in the thread menu: Download thread.** It saves the whole conversation as one Markdown
  file, which you can give to any other model as context.
- **The file:** a header with the thread's name, project, tool, model, folder and dates, then every
  message, oldest first, as `## You` and `## Assistant` sections. Each tool call is one short line
  (for example `→ Bash: npm test`), without its output. Thinking and internal notices are left out.
- The daemon builds the file from the thread's whole history, not only the part on the screen. Only
  you can download it. It works for Claude, Codex, Grok and OpenCode threads.

## A simpler thread menu

- **No "More".** Every option shows directly, on the desktop and on the phone.
- **On the phone**, the menu opens at a fixed height and never reaches the top of the screen. The four
  buttons (Rename, Branch, Account, Alerts) stay at the top, and the list under them scrolls.
- **Thread details** is an ordinary row on the phone, not a separate section.

## Updating

Needs a daemon rebuild and restart (a new export route): run `dispatch update`, then reload the app.

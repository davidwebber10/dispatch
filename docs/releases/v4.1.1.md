# Dispatch v4.1.1 — Codex Business accounts show in Usage

## What was wrong

- A Codex account on a ChatGPT Business plan did not show in Usage limits or as a ring. Codex
  reports no 5-hour or weekly limit for that plan, only a credit allowance, and Dispatch read only
  the 5-hour and weekly limits.

## The change

- Usage now reads that allowance as a **Credits** limit: how much of it is used and when it
  resets. The account gets its card in Settings → Usage limits and a ring in the header.

## Updating

Daemon and web client. Run `dispatch update` (or `./bin/dispatch update` from the repository
folder), then reload the app.

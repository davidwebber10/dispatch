# Dispatch v4.5.1 — agents stop repeating their answers

## The change

- **No more doubled answers.** After an agent reports its status, it now ends with one short
  closing line. Before, it was told to write nothing more, so it sometimes ended with an empty
  message. Claude Code then asked it to continue, and it wrote its whole answer a second time.
- **Reports keep the real answer.** The notice that a finished agent sends, the summary on the
  board, and the task that a waiting agent receives now carry the agent's report and any short
  answer, not only its closing line.
- **Scheduled roles keep their result.** A role run reads the last result block of its turn, so a
  failed run is not recorded as a success.

## What was wrong

On one machine, 31 answers in 14 days got the "no visible output" prompt, and 13 of them came out
twice. The repeats used extra output tokens and counted against usage limits.

## Known limits

- The closing line is an instruction to the model. Repeats should become rare, but not impossible.
- Codex, Grok and OpenCode threads can still save the closing line as their turn summary.

## Updating

Needs a daemon rebuild and restart: run `dispatch update`. New threads get the change at once.
Running threads get it when they restart.

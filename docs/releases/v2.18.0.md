# Dispatch v2.18.0 — Analytics: token usage, throughput and personal stats

## The change

A new **Analytics** view — a third destination beside Threads and Board on desktop, a
fifth bottom tab on mobile. It answers three questions: how many tokens you used and
where they went, how much work the fleet actually did, and what your all-time numbers
look like.

- **Headline tiles** — total tokens, output tokens, turns, threads.
- **Tokens over time**, stacked by model. **Output tokens** on their own chart, since the
  cumulative total is dominated by cache reads.
- **Turns per day by outcome**, and **average turn duration**.
- **Model mix** and **top projects**, ranked.
- **A 26-week activity calendar**, and an all-time **personal records** panel.
- **Import history** — a manual, one-off, undoable backfill from your existing
  transcripts.

Filter by project, provider, and date range. The page updates live as you work.

## How it records

Nothing polls and nothing scans on a timer. The daemon already emits turn-boundary
events, so a recorder subscribes and writes one row per turn as it happens. Usage lands
in the row as each frame arrives, so a daemon restart mid-turn loses nothing.

**PTY threads are covered too**, which is roughly half of all threads — 233 PTY versus
215 structured across this install's history. They emit no frames, so their usage is read
from the provider's own transcript when the turn ends:

- **Claude Code** carries per-message usage and no running total, so a turn is the sum of
  messages since the last read. That needs a byte cursor.
- **Codex** carries a monotonic running total, so a turn is a diff — which needs no
  cursor, and is therefore immune to the file-moved and file-rewritten problems the
  cursor has to defend against.

**Grok records nothing** and says so. It has no transcript, no session id, and no
lifecycle event; its threads surface as "usage not reported", never as a measured zero.

## Honesty rules baked in

- A turn whose usage was never reported is **counted separately**, never shown as zero.
  A Codex turn can end through its error path without emitting a usage frame; those turns
  really did spend tokens, we simply never got a count.
- A turn interrupted by a daemon restart is closed with **zero duration**, so a restart
  after a break cannot appear as a multi-hour turn.
- A PTY row carries no duration either — a transcript records no turn start, and an
  absent number beats a plausible wrong one.
- The **import cutoff** is stamped when recording begins, and the importer accepts only
  data strictly older than it. Live recording owns everything after. So pressing Import
  history twice cannot double-count.

## What was wrong

- **Codex history never imported.** The backfill route called the Claude-only transcript
  resolver for every provider, so every Codex thread silently imported zero rows. It
  failed by finding nothing rather than by erroring, which is why it went unnoticed.
- **Model prices were wrong.** The pre-existing session-stats route priced
  `claude-opus-5` at 3× its real rate, `fable-5` at Sonnet rates, and `haiku-4-5` 20%
  low. The table is now one shared module, verified against a real billed transcript
  whose reported cost reproduces to seven decimal places, and it covers the previous
  model generation again — which the Done-card cost chip had lost.

## Under the hood

- `usage_turns` and `usage_pty_state` tables, both additive — an older database upgrades
  in place and a downgrade still runs.
- The turn-settled hook became a subscriber list; it previously replaced rather than
  appended, so a second consumer would have silently disabled push notifications.
- Recharts is lazy-loaded into its own chunk (417 kB, 121 kB gzipped) with zero
  references in the main bundle, so the cost is paid only by opening the view.
- 56 commits, ~120 new tests.

## Updating

Needs a **daemon rebuild and restart** — the recorder, the query layer and the routes are
all in core. Hard-refresh the browser afterwards; the web bundle changed.

**Analytics starts empty.** Live recording captures turns from the moment it starts, so
press **Import history** to backfill from your existing transcripts.

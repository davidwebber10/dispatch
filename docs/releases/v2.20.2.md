# Dispatch v2.20.2 — Files search finds hidden folders, and Grok scrolls on a phone

## The change

- **Files search follows the `·*` toggle.** Turn on show-dotfiles and search
  finds `.env`, `.dispatch/…`, `.github/…`, and other hidden paths the tree
  already showed. Gitignored bulk (`node_modules`, nested worktrees) stays out.
- **Grok scrolls on mobile.** A swipe on a Grok thread now moves the TUI
  scrollback. The mobile key row also has **PgUp** / **PgDn**.

## What was wrong

Search used `git ls-files --exclude-standard`. The tree is a raw directory
listing, so the toggle revealed hidden folders that the search index never
contained.

Grok runs a full-screen TUI on the alternate screen. The mobile overlay
scrolled xterm, which has no history there, so the swipe did nothing. Claude
Code Pretty was never on this path — it scrolls its own chat list.

## Under the hood

- `/files/flat` merges gitignored hidden files into the index after the
  git-visible set, still capped at 20k.
- On an alternate buffer, a swipe sends SGR mouse-wheel ticks to the PTY
  (Grok already listens for the scroll wheel). The normal-buffer xterm path
  is unchanged.

## Updating

Needs a **daemon rebuild/restart** (`dispatch update`). Both the Files
index and the mobile Grok swipe live in the rebuilt bundle.

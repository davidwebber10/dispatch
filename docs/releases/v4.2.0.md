# Dispatch v4.2.0 — switch models in Pretty, and sign back in from the chat

## At a glance

- **Switch the model in Pretty.** A chip under the message box shows the model in use; tap it to
  pick another. The conversation carries on.
- **The model name is always right.** Pretty shows the model the tool reports, also after you
  switch to CLI, change the model there, and come back.
- **Signed out? Sign in from the chat.** A card names the account and opens its usual sign-in, or
  lets you switch account, then Retry.
- **No more "This thread is asking you" strip.** A thread's question stays in the thread itself.

## Pretty and models

- The chip shows a friendly name (for example Opus 5.5). On a phone the list opens as a sheet, on
  a computer as a card. A "Model switched to …" line marks the change in the chat.
- The switch happens in the running session for Claude Code, Codex (from the next turn), Grok and
  OpenCode. It is off while a turn runs, and the chip says why.
- A model you change in CLI mode (for example with `/model`) is the one Pretty runs and shows when
  you switch back, for Codex too.
- Thread details name the active model.

## Signed-out accounts

- When a Pretty thread's account is signed out or its login expired, the chat shows
  "**Account** is signed out" with **Sign in** (the same sign-in as Settings → Accounts) and
  **Switch account**, instead of a raw error. After you sign in, **Retry** sends your last message
  again.
- Signing an existing Claude account in again updates that account instead of adding a copy.

## Updating

Daemon and web client. Run `dispatch update` (or `./bin/dispatch update` from the repository
folder), then reload the app.

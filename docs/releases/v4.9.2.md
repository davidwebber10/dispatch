# Dispatch v4.9.2 — the open tab shows where to type

## The change

- **On the desktop, opening a thread shows you where to type.** Each time a thread becomes the open
  tab (from the tab bar, the sidebar or Cmd+K), it takes the keyboard focus and shows a short green
  pulse that fades out in about half a second.
  - **Pretty thread:** the composer gets the focus and the pulse.
  - **CLI thread:** the terminal gets the focus (you type at the CLI's own prompt), and the
    terminal's frame gets the pulse.
- **On the phone, nothing changes.** A focus there would open the keyboard.

## Updating

Web only: run `dispatch update`, then reload the app.

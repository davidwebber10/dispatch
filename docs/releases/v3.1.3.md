# Dispatch v3.1.3: the Chat gaps left open in v3.1.2

Closes the known gaps listed in the v3.1.2 notes.

## The change

- **Pictures inside links behave like links.** A picture wrapped in a link is one Tab stop,
  and clicking it follows the link instead of opening the viewer.
- **AI reply images stay open.** An image opened from an AI reply no longer closes its viewer
  when the reply finishes.
- **A failed send after you leave Chat tells you about lost images.** The text is still saved
  to your draft. If images were attached, the Chat box now shows how many could not be saved.
  If only images were attached, the notice no longer says text was restored.
- **Focus returns sensibly.** Closing the image viewer puts focus back where you were, or on
  the Chat box if that spot is gone.

Known limits:
- The lost-images notice does not survive a page reload.
- Not yet tested on an iPhone.

## Updating

Web app. Run `dispatch update`, then reload the page.

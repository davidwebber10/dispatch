# Dispatch v3.0.2 — no project chips in Chat

The row of project chips at the top of Chat is gone for now.

## The change

- **No project filter in Chat.** The chips (All, and one per project) showed only the
  messages that had a project tag. Most messages get no tag unless you pick a project before
  you send, so the chips showed little. Chat now always shows the whole conversation, and the
  memory search always searches all projects.
- The projects button left of the attach button still works: pick a project to point Dispatch
  at it for one message.

## Updating

Web app only. Run `dispatch update`, then reload the page.

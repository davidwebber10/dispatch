# Dispatch v3.19.0 — usage bars, a new thread header, tidier Settings

## The change

- **Usage sheet:** one card per tool. Each limit gets a bar that goes green, yellow, then red. The reset time and run-out estimate sit under it. Banked Codex resets have their own row with Use one.
- **Thread header:** it shows the thread name with a status dot. Project and mode sit underneath. Previews and Switch to Pretty/CLI moved into a ⋯ menu.
- **Threads view:** Mine, Agents and All now sit behind a Filters button. Applied filters show as pills you can remove. The default is All.
- **Composer:** it is 60 px on a phone. An empty box stays on one line. The usage chip shows only the percent.
- **Settings:** 11 sections in 3 groups, You, Agents and This Mac. Dictation settings and the Control Plane name are now stored on the daemon, so every device sees the same values.

## What was fixed

- A CLI thread redraws when you come back to it. A screen scrambled by another device settles.
- Claude Code's bullet shows as ● on iOS, not an emoji square.
- Dictation keeps the screen awake while it records. If the page hides anyway, it stops and transcribes what you said.
- You can switch between CLI and Pretty in the middle of a turn. You confirm first. The turn stops and the conversation resumes in the other mode.
- The usage gauge had six wrong figures or wrong pushes:
  - Several working Codex threads now all stay current. Up to 4 are read per tick.
  - A custom `CODEX_HOME` is used for the login and the figures.
  - A paused Codex with no figures now shows on the chip, red with a dash.
  - An account switch updates open clients.
  - A late summary can no longer overwrite a newer one, even after a clock rollback.
  - The idle resend now fires once the forecast time has passed.

## Under the hood

- The count-up test runs on one clock, so it no longer flakes.
- The old unused settings and the duplicate connection block are removed. Old section keys still resolve.

## Updating

Run `dispatch update`, then reload the app on each phone. There is no database migration.

# Dispatch v4.0.0 — plugins, the Coach, themes, and a cleaner phone app

## At a glance

- **Plugins.** Add screens, tabs, menu items and tools to Dispatch. Two come built in: Previews
  and the new Coach.
- **The Coach.** One small, useful tip at a time about how you work with AI. On by default; you
  choose how often and what it may spend.
- **Themes and light mode.** Settings → Appearance.
- **Every account's usage, right away.** Added accounts show their limits as soon as you add them,
  and a thread shows only the account it uses.
- **Codex accounts sign in with a code**, so adding one works from a phone.
- **A cleaner app.** New thread menu, one filter design everywhere, no more system dropdowns, and
  phone tabs that remember where you were.

## Plugins

- A plugin can add a screen (the desktop rail, the phone's Plugins tab, or a tab of its own), a
  right-column tab, Settings, thread and project menu items, composer and header buttons, and ⌘K
  commands.
- **Settings → Plugins** lists them with an on/off switch. Tap one to see what it may read, in
  plain words, its status, and its actions.
- **Marketplaces** are git repositories. Add one by URL in Settings → Plugins; a private
  repository is a private marketplace. Install, update, roll back and pin from there.
- **Removing a plugin keeps its data** unless you choose to delete it, and you can download its
  data and settings first and import them later.
- **Skills**: Settings → Skills turns them on per project.
- **Previews is now a plugin.** It works as before, with search and filters by project and
  thread. Your old previews move over on the first start.
- Building one? Read `docs/plugins.md`.

## The Coach

- Replaces the Prompt coach. At a natural break it suggests one small next step, toward goals you
  can set.
- It can suggest a skill (review it, then create it in one click) or a plugin to automate
  something.
- Ask it questions about your own use, or ask it to review a thread, a project or your last week.
  It shows the cost first, and it says so when it has too little to go on.
- You choose how often it speaks, what it remembers, which projects it looks at, and what it may
  spend (default: 3% of your weekly limit). Its data stays on your machine.
- If you had turned the Prompt coach off, the Coach starts off too.

## Accounts and usage

- **Added Claude accounts show their usage at once**, without using them first.
- **Codex accounts sign in with a link and a short code.** A failed sign-in says why, and an
  account with no login has **Sign in again**.
- **In a thread**, the usage ring shows only that thread's account. Tap it: that account is
  marked **This account** and listed first.
- **The ring counts the 5-hour and weekly limits.** A model's own limit (for example Fable) counts
  only in a thread on that model.
- **Settings → Usage limits** can show the percent used in the ring instead of the logo.

## Easier to use

- **Thread menu (⋯):** four tiles (Rename, Branch, Account, Alerts), then View, Plugins, a folded
  More, and Archive last. The desktop opens the same menu with a right-click.
- **One filter design:** Threads, Previews and Analytics share the same search, Filters button
  and removable filter pills.
- **No system dropdowns:** every dropdown in the app is the same searchable menu.

## On the phone

- **Bottom tabs remember where you were.** Tap the tab you are on to go back to its top; on
  Projects, each tap goes up one level.
- **The CLI view:** the message box grows over the terminal instead of pushing it up, and a handle
  shrinks it to two lines. The new keyboard button next to + opens a short panel of keys; swipe for
  more.
- **Long thread names** scroll slowly instead of ending in "…".
- The Plugins tab is a plain list, and a plugin opens with a back arrow like a thread.

## Also fixed

- A file named only by its name in a chat (for example `LEARNINGS.md`) now opens wherever it is in
  the project.

## Updating

Daemon and web client. Run `dispatch update` (or `./bin/dispatch update` from the repository
folder), then reload the app. On a phone, close and reopen the app if it still looks old.

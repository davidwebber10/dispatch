# Dispatch v3.20.0: usage as claude.ai shows it, Codex kept current, spend and credits

## The change

- **Claude usage now matches the claude.ai usage page.** The daemon reads the account's usage
  from Anthropic with the Claude Code login it already holds. No new sign-in. The Usage sheet,
  the Details pane and the context popup show the weekly window, the **Fable** window, Opus and
  Sonnet when the plan has them, and the 5-hour window, with the same percents as the page. The
  plan name ("Ultra") shows on the card. Figures refresh every two minutes while anything runs.
- **Extra usage and credits.** Claude's card shows "Extra usage $2.51 of $1,000.00 this month".
  Codex's card shows its prepaid credit balance.
- **"Fable weekly" was not Fable.** The row came from a Claude CLI figure that is not a model
  window. It read 11% while claude.ai said 18%. That figure is hidden now and no longer counts
  toward warnings. A Fable limit pause now points at the real Fable window.
- **Codex stays current.** After a daemon restart, a Codex thread looked active for ten minutes
  and kept the daemon reading its old session file instead of asking Codex. Codex was missing
  from the sheet meanwhile. The daemon now asks Codex directly whenever no thread gives a newer
  figure.

## Under the hood

- `limits/claude-usage.ts`: `GET /api/oauth/usage` and, hourly, `/api/oauth/profile`. The token
  comes from Dispatch's saved login, else the CLI's credentials file or the macOS keychain item,
  whichever expires later. The token is never refreshed by Dispatch; a failed read falls back to
  the old tiny-turn probe, which makes the CLI refresh it.
- Snapshots carry `spend` and `creditBalance`; the summary and the Details route pass them on.
- `codex-refresh` returns whether it recorded; the gauge polls Codex when nothing was recorded.
- Tests: the parser on a real response shape, the reader, the token order, the gauge's read
  cadence and fallback, the Codex poll gap, the sheet's money lines.

## Updating

Needs a daemon rebuild and restart. Run `dispatch update` (or `./bin/dispatch update` from
the repository folder), then reload the app.

# Dispatch v3.4.2: thread reports reach Chat

A fix release (#105). Nothing to set up.

## What you will notice

- **Chat now hears when a thread finishes work it started itself.** Before this fix, a thread
  that waited on its own helpers (sub-agents or reviewer threads) went quiet after the first
  report. Its later updates and its final result never reached Chat, so the thread showed as
  waiting while the work was done. Now each of those turns reports when it ends.

## Cause

A thread was marked busy only when someone sent it a message. A turn that the thread started
itself, such as waking up when a helper finished, never opened. Its end was ignored, so no
report went out. A turn now opens when the thread starts replying (a parent assistant message
or the start of a streamed message). Helper and late stream frames do not open a turn.

## Known items

- Checked with automated tests only. No live run yet.
- Claude Code threads are fixed. Grok and opencode threads were not checked.
- A `/compact` in a thread may produce one extra report.
- Short (8-character) thread ids still return "unknown thread" in some tools.

## Updating

Run `dispatch update`, then reload the app.

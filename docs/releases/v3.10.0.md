# Dispatch v3.10.0 — Claude Code threads skip agent status summaries

## The change

- **Fewer tokens spent by Claude Code threads.** Since Claude Code 2.1.232, every ~30 seconds
  and for each background agent, Claude Code sends that agent's whole transcript to its model
  (usually Opus) only to get a 3–5 word status line for its agents panel. Public measurements
  put this at 16–26 % of all Claude Code spend. Dispatch now turns it off in every Claude Code
  thread it starts.
- **A new setting.** Settings → Harnesses → Claude Code → **Skip agent status summaries**. It
  is on by default. Turn it off to get the status lines back. The change applies to threads
  started after it.
- **What you lose:** a background agent's short status line in Claude Code's own panel stops
  updating. Subagents and background agents run as before.

## Under the hood

- A small Bun preload (Flamerix `no-agent-summary.js` v3, MIT) is copied to
  `~/.dispatch/preload/` and added to `BUN_OPTIONS` in the thread spawn environment. It loads
  only inside Claude Code and stops only the one summary timer.
- If a Claude Code update renames what the preload looks for, the summaries come back and
  threads keep working; nothing breaks.
- Tests: the setting's default, off and reset; the `BUN_OPTIONS` merge; the toggle.

## Updating

Needs a daemon rebuild and restart. Run `dispatch update` (or `./bin/dispatch update` from
the repository folder), then reload the app. Threads that are already running keep the
summaries until they restart.

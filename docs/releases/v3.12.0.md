# Dispatch v3.12.0 — thread menu, better titles, phone fixes

## The change

**Every thread's ⋯ menu** (phone and desktop) now has:

- **Thread details**, on the phone: the desktop's right panel as a sheet.
- **Reload thread.**
- **Reset status**, for a thread stuck on working, needs-you or error. It goes back to idle
  without counting as activity, so no "finished" push and no reset of its auto-archive timer.
  The desktop Details panel has the same button.
- **Branch thread** for Codex and Grok as well as Claude Code. OpenCode can't branch yet.

**Thread titles** come from your own signed-in tools first: Claude Haiku 5.5 through Claude
Code, then Codex (6.1 Terra when your account lists it, otherwise 5.6 Terra), and only then
OpenRouter. A tool that isn't signed in is skipped. A short name still shows within 3
seconds, and the proper title replaces it when it arrives.

**Phone**

- The status bar is now solid, so iOS 26 no longer blurs over the header. **Remove the app
  from the Home Screen and add it again** to pick this up; iOS only reads it at install.
- The first bottom tab reads Threads, with a terminal icon, while the Threads view is on.
- The Threads view uses the same rows as a project: ⋯ menu, timers, and swipe left to archive.
- Closing a card under a terminal during a turn no longer leaves an empty band.

**Settings → Harnesses** has a default auto-archive for each harness. New Thread opens with
it, so Claude Code threads can archive themselves after 24 hours, for example.

**Chat** uses the Control Plane composer's shape. Its + opens Project, Add file and Dictate,
on desktop and phone.

**Analytics**: the Usage charts show every day of the range; a quiet day is a zero, not a gap.

## What was wrong

Titles were usually just the first words of your message. The title model had 3 seconds,
which also covered fetching its key, and it now takes 2 to 3 seconds by itself, so it
usually ran out of time and its answer was thrown away.

## Updating

Run `dispatch update`, then reload the app on each phone (and re-add it to the Home Screen
for the status bar). There is no database migration.

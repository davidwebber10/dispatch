# Dispatch v4.13.1: opening a finished run no longer starts it again

## The fix

- **A finished scheduled run stays finished.** Before, opening the Raw or Terminal tab of a run that had ended could start it again, and the run did its whole job a second time. One board refresh ran twice this way and cost a second full run.
- **The run page says "This run has finished"** in place of a live terminal for a run that has ended.
- **Relaunch still works.** You can still start a run again on purpose from its menu.
- **Idle runs show their output.** A run that is idle, not finished, keeps its Raw tab.

## Limits

- You cannot yet read the terminal output of a finished run from its page.
- A direct connection to the terminal of an archived role run can still start an empty process. This was already true before this release, and a later fix will close it.

## Install

This needs a daemon rebuild and restart (`dispatch update`). A browser refresh is not enough.

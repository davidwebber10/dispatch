# Dispatch v3.16.0 — Control Plane looks like a Pretty thread; threads sorted by recent activity

## The change

**Control Plane uses the Pretty thread view.** The coordinator's conversation is now drawn by the
same renderer as a Pretty thread, so the two read alike: your messages are "YOU" bubbles, the
coordinator's reply sits flush left, and each turn is separated by a hairline. Everything that
only Control Plane has is still there: the agent cards (spawned, queued, messaged, started; tap one
to open the agent), the agent notices ("Agent … finished", "… is blocked"), direct-message cards,
ledger chips, status cards, answered questions and cost footers.

This is the first step toward one conversation renderer instead of three. Chat comes next.

**Threads are sorted by recent activity.** Inside a project, threads now lead with the most
recently active, as projects and the Threads view already do. If you had never picked a sort, or a
drag had switched a project to Custom, that project now follows the new default. A sort you chose
(Name, Newest, …) stays, and dragging a thread still switches that project to Custom.

## Known limits

The new Control Plane look was checked with a sample conversation at desktop and phone size, not
with a long real coordinator history.

## Updating

Run `dispatch update`, then reload the app on each phone. There is no database migration.

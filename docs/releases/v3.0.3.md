# Dispatch v3.0.3 — faster login errors, and log in from threads

A Chat reply that fails on the Claude login now fails in seconds, and Pretty threads can log
in to Claude too.

## The change

- **No more 30-second wait on a failed login.** Before, when Claude's login had expired, Chat
  showed "Working…" for about 30 seconds before the error. Chat waited for its summaries, and
  a failed summary tried again only after the next message. Now the wait tries each failed
  summary once more and stops as soon as it fails again, so the error shows in a few seconds.
- **Log in to Claude in Pretty threads.** When the last turn of a Claude Pretty thread fails on
  the login, the red error has a **Log in to Claude** box under it: open the Claude login page,
  sign in, and paste the code. Then send your message again. The login works for Chat and for
  every Claude thread on that machine.

## Updating

Daemon and web app. Run `dispatch update`, then reload the page.

# Dispatch v2.37.0 — new thread picker, OpenCode model settings, unified harness telemetry

## The change

**A new New Thread panel, on desktop and on the phone.** The harness picker is a single
strip (a scrolling row of pills on the phone). Mode, Model, and Auto-archive are plain
settings rows. Auto-archive is always visible, with its duration inline. The resume list
folds behind "Or resume a recent … session" with a count. The Name field and the Advanced
fold are gone; name a thread from the sidebar as before. The desktop card is pinned at the
top, and the phone sheet keeps its height, so switching harnesses no longer makes the panel
jump.

**Searchable model picker.** Every Model row is a searchable select. Type to narrow the list
by label or id, arrow keys move, Enter picks, Escape closes just the popover.

**OpenCode models are yours to curate.** Settings → Harnesses → OpenCode now lists the
models the picker offers. Remove any, reset to the defaults, or search OpenRouter's live
catalog and add one with a click. Aliases that always resolve to a family's newest model are
marked LATEST and show what they resolve to today. An id the catalog does not know can be
added as typed.

**Codex offers GPT-6 Astra.**

**Threads are named from your first prompt**, and a manual rename is kept.

**Board navigation is hidden** along with its mobile preference.

## What was wrong

OpenRouter renamed its family aliases to a `~` prefix (`~anthropic/claude-opus-latest`).
The old ids, and `openai/gpt-latest`, return 404, so most OpenCode picks failed at spawn.
The defaults now use the live ids and gain Claude Sonnet, the four GPT families, GLM Flash,
and DeepSeek Pro.

## Under the hood

- Harness capabilities, lifecycle events, and usage accounting are centralised in one
  runtime layer with typed events, transactional recording, and diagnostics. Includes a
  database migration; it runs on the first start.
- The daemon serves the effective OpenCode model list and a cached OpenRouter catalog search
  (`GET /api/settings/harnesses/opencode/catalog?q=`).
- The shared modal shell gains a title-less mode, a phone bottom sheet, and a top anchor.

## Updating

Daemon-side: `dispatch update` (pull, rebuild, restart). The OpenCode list, the catalog
search, and the telemetry changes only take effect after the daemon restarts; a browser
refresh alone shows the new panel but an empty OpenCode list until then.

# Dispatch v3.17.1 — phone Threads filter: Mine / Agents / All

## The change

On the phone, Projects › Threads now has a **Mine / Agents / All** switch above the active list, so
the threads you started are no longer buried under the review and build threads agents open.

- **Mine** shows threads you started yourself. It is the default.
- **Agents** shows threads started by Chat, an overseer or another thread, including ones you asked
  Chat to start. Each row says who started it ("Chat", "via …").
- **All** shows everything, as before.
- Each option shows its count. The project chips and search work inside the chosen filter, and an
  empty list offers a button to the filter that has matches.
- Typing in an agent's thread does not move it to Mine.
- The choice is remembered on each device. Archived threads and the desktop are unchanged.

## Updating

Run `dispatch update`, then reload the app on each phone. There is no database migration.

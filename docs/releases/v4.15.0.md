# Dispatch v4.15.0: a new Chat header, a Working pill, and an Inbox that fits on a phone

## The change

### Chat

- **The top of Chat is one row.** It shows the model, a search, Threads, the usage ring of Chat's account, and a menu with three dots. On a phone the row sits in the app header.
- **Threads replaces Projects at the top of Chat.** It lists only the threads that Chat started. A pill at the bottom right shows how many of them run.
- **Chat can run on its own Claude account.** Pick the account in the menu. The change applies from the next message. Codex accounts cannot run Chat.
- **Chat keeps your place.** Open another view and come back: Chat shows the same message at the same place. A full reload still opens at the end.

### Working pill

- **A run of tool calls folds under one row.** While it runs, the row shows a spinner, the current step in plain words, the time and the step count. When it is done, it shows one line, such as "12 steps · 4 read · 2 edited".
- **One tap opens the calls.** A failed call stays in sight under the closed row.
- This works in the thread view, the worker view, Chat and the Control Plane, for every provider. The OS look still shows each call as its own row.

### Tool calls

- **An open tool call keeps its scroll position.** Before, a new call of the same tool closed it and sent it back to the top.

### Inbox (1.3.0)

- **Two views: Rows and Cards.** Rows is the default. The Inbox remembers your choice on all your devices.
- **A tap opens an item in place.** The search is behind a magnifying glass. The key button is now **Send Secret**.

### Phone and thread list

- **Drag projects on a phone.** Each project row has a grip. Hold the grip and drag.
- **On a phone, the Threads list has Filters and + at the top,** next to the search, as the Projects list does.
- **On the desktop, the Filters button of the Threads list is an icon alone,** the same size as the + beside it.
- **The Threads icon is the same everywhere:** stacked rows.
- **Threads that an agent started have a small badge,** so your own threads stand out.
- The phone Threads header has better spacing.

### New Thread

- **No Project field while a tool is not installed.** The window shows only the install card. After the install, the Project field comes back with your pick.

### Agents

- **Builder threads run on Opus by default.** The coordinator and the implementer move from Sonnet to Opus. A spawn can still ask for Sonnet.
- **Chat can switch the model of a thread that it started.** It can also set the worker models of the Control Plane. Thread keys and plugin keys are still refused.

### Plugins

- **Dispatch installs plugins built for SDK 2.**
- **Plugins get `ui.SortableList`,** a list the user reorders by a drag, with an optional grip for phones.
- **Composer actions can send.** `ctx.send(text?)` sends at once. Composer favorites 0.2.0 uses it.

## Updating

Needs a daemon update: run `dispatch update`, then reload the app.

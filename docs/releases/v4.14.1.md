# Dispatch v4.14.1 — HTML pages in the Inbox open again

## The change

- **An HTML page or a pdf in the Inbox opens again.** Before, the viewer showed only a white page.
  The daemon told the browser that no page may show its files in a frame, and the viewer shows HTML
  and pdf files in a frame of Dispatch itself. Now Dispatch's own pages may frame them, and no other
  site may.
- An HTML page still runs in its sandbox: its scripts have no access to Dispatch.

## Updating

Needs a daemon rebuild and restart: run `dispatch update`, then reload the app.

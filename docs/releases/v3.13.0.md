# Dispatch v3.13.0 — one composer, a Keys sheet and upload progress

## The change

**One composer everywhere**, modelled on ChatGPT's: a rounded box with **+** on the left, your
text, a **mic** and a round **↑** to send (a Stop while a reply is running). It is the same on
a CLI thread, a Pretty thread, Control Plane and Chat, on desktop and phone.

- The text wraps and the box grows with it, up to half the window, then scrolls.
- Dictation moved from the + menu to the mic. It is greyed out until Settings →
  Transcription is set up.
- In Chat, the + also holds the Project choice.

**Keys sheet** (phone, CLI threads). The row of keys under the terminal is gone, which gives
the terminal that line back. Tap **+ → Keys** for a bigger sheet:

- The old keys, plus Tab and arrows.
- **Clear input** for Claude Code and Codex: empties whatever is typed in the agent's prompt.
- Mode (Shift-Tab), Ctrl-R, Ctrl-B and Ctrl-C for Claude Code; Ctrl-T and Ctrl-C for Codex;
  Ctrl-D, Ctrl-L, Ctrl-R, Ctrl-Z and more for a shell.
- The sheet stays open between taps; Done closes it.

The + menu also has Slash commands, Previews and the Autocorrect toggle.

**Upload progress.** Each image or file you attach shows a tile with a progress ring and a
percentage, and an × that cancels it before it finishes. A failed upload stays, marked red,
until you clear it. Send waits until uploads finish, so an image never misses its message.

**The bottom tab bar stays on a thread** (phone). Tapping Projects in a thread goes back to its
project; tapping again goes to the project list. With the Threads view on, one tap goes
straight back to the thread list.

## Known limits

Not tried on a real phone yet: the mic in the new spot, and upload progress over a slow
connection.

## Updating

Web only. Run `dispatch update` (or reload the page once the daemon has the new build), then
reload the app on each phone. There is no database migration.

# Dispatch v2.34.1 — file links in the Control Plane open and stay put

## The change

Clicking **View file** on a tool row in the Control Plane stream now opens (or reuses)
that file's tab in the project — and keeps you exactly where you are. The tab waits on
the Threads surface; the Overseer never navigates away, and on mobile you are never
yanked out of the stream mid-read.

The agent chat's own View file behavior is unchanged (you are already on the Threads
surface there, so the file still comes to front).

## Under the hood

- New shared `lib/openFileTab(sessionId, path, { focus })` — the body of ChatView's
  `openFileInViewer`, extracted. `focus:true` = ChatView (navigate), `focus:false` =
  Control Plane (stay put). Reuses an existing file tab per path, so repeated clicks
  never pile up duplicates.
- The stream threads `onViewFile` through to the shared `MachineryStrip`.
- Tests: 4 `openFileTab` unit tests + 1 end-to-end stream test.

## Updating

**Web-only** — after `dispatch update`, a browser refresh is enough; nothing in core
changed.

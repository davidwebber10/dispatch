# Dispatch v2.23.1 — an honest empty chat

## The change

An empty Pretty chat now tells the truth while the connection is down. Before,
a thread opened mid-reconnect said "Send a message to start the conversation"
— over a thread that may be full of messages the socket simply hadn't replayed
yet. That state is now a centered spinner with "Reconnecting…"; the start-a-
conversation prompt only appears once the socket is open and the thread is
genuinely empty.

## Updating

**Web-only** — a browser refresh is enough.

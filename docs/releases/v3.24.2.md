# Dispatch v3.24.2: a sent message settles the resume choice

## The change

- The "This session is … old and … tokens" card (resume from summary, or the full session)
  hides as soon as you send a message, without a button press. A message resumes the full
  session anyway, so the decision is made. It stays hidden for that resume, and asks again
  on a later resume of the same thread, as before.

## Updating

Web client only. Run `dispatch update` (or `./bin/dispatch update` from the repository
folder), then reload the app.

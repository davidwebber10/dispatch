# v2.25.1 — describe the prompt, don't obey it

One fix: the GLM thread namer titled imperative prompts by following them.

## Thread namer: opener framed as data

"Write me a long poem" got the thread name "Epic Journey Through Time" —
the model obeyed the prompt and invented a poem title (5 of 6 runs). The
conversation opener is now wrapped in `<conversation>` tags with an explicit
data-not-instructions system prompt: the same opener titles as
"Write a long poem" (6 of 6), and instruction-override attempts inside an
opener ("ignore all previous instructions…") get described, not followed.

Threads named before this fix keep their names — rename by hand if one
bothers you.

## Updating

**Core** — pull and restart the daemon (`dispatch update` does both). The
fix applies to threads named after the restart.

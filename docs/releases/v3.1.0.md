# Dispatch v3.1.0 — update progress, a game while you wait, and a safer port

Updates now show what they are doing, step by step, and you can play a game while they run.
Dispatch also protects its port, so an agent's dev server can no longer take over the window.

## The change

- **See the update run.** The update window lists the steps — Downloading, Installing
  packages, Building, Updating tools, Restarting — with the current one marked and the time
  that has passed. **Show details** shows the latest lines of the update's output.
- **Errors you can act on.** If a step fails, the window shows the step, the error and the
  last lines of output, with **Retry** and **Close**. A failure before the restart leaves the
  old version running, so nothing breaks.
- **Hide it.** **Hide** closes the window while the update continues; a small badge shows the
  step and opens the window again.
- **Done, on your terms.** When the update is done, the window says so, with **Reload now**
  and **Keep playing**. If nobody touches anything for 15 seconds, the page reloads by itself.
- **Faster updates.** An update skips `pnpm install` when the dependencies did not change.
  This saves 10 to 20 seconds on most updates.
- **A game while you wait.** The terminal rain is now a top-down space blaster, and the status
  card is a wall in the arena. Up thrusts, Left and Right turn, Down brakes. Space fires the
  blaster, Q a missile, E a heat-seeker, R a mortar that flies over the card, and F an A-bomb
  that clears the screen but costs you a life. Waves get harder; your best score is kept on
  each device. On a phone, drag to move; the blaster fires on its own, and buttons fire the
  rest.
- **Dispatch keeps its port.** Threads no longer get Dispatch's `PORT` setting, so a dev
  server that an agent starts does not pick port 3456. Dispatch also holds `127.0.0.1` and
  `::1` on its port, so no other program can take `localhost:3456` while Dispatch runs. Before,
  such a server could make the Dispatch window show another app's page, or make Claude
  threads stop reporting their status.

## Updating

Daemon and web app. Run `dispatch update`, then reload the page. The new update window and
the game show from the next update after this one, because this update still runs on the
old updater.

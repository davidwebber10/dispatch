# Dispatch v3.24.1: a clearer Switch account note

## The change

- The note under the account list no longer starts with the thread's name. A long name made
  it read as one run-on sentence. It now reads: This thread restarts under “Work” and resumes
  its session.

## Updating

Web client only. Run `dispatch update` (or `./bin/dispatch update` from the repository
folder), then reload the app.

# Dispatch v4.3.0 — The Coach reads only your words, and is off by default

## At a glance

- **The Coach is off by default.** If you never turned it on yourself, it turns off with this
  update. If you turned it on, it stays on. Turn it on in Settings → Plugins.
- **The Coach reads only your own words.** Messages between agents, agent "finished" notices,
  watch wake-ups, compaction summaries and file-attach lines no longer count.
- **Short go-aheads are not tips.** "proceed", "continue", "status", "cut release" and other
  short replies never start a tip.
- **A markdown reader for text previews.** A report sent as text now shows as a formatted
  document, with a Read button that opens it full screen.

## The Coach

- Reviews and the 30-day look back skip the threads of agents.
- A review finding must quote your own line. Findings come from each thread in turn, not from
  the first thread only.
- A tip shows only when the model answers yes to two questions: "Are these your own words?" and
  "Would a tip change your next prompt?" Otherwise the Coach says nothing.
- More evidence before a tip, a confidence floor of 0.85, and the same kind of tip does not come
  back within 14 days.
- After the update, the Coach cleans its old notes one time. An old look back shows as out of
  date with **Run again**.

## Previews

- A text preview that looks like markdown (or has a `.md` title) renders as a document on the
  card. **Read** opens it in the full-screen viewer. Commands, links and tokens keep the plain
  box that you can copy.
- The viewer now has a solid backdrop for text and markdown, and Download works for an inline
  text file.

## Updating

This release changes the daemon. Run `dispatch update` (or `./bin/dispatch update` from the
repository folder). The daemon restarts once. Then reload the app.

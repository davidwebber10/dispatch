# Dispatch v4.14.2: a private https marketplace works when you are signed in with gh

## The change

- **A private marketplace with an https address now works for a person who is signed in with the GitHub CLI.** Before, the clone could fail with `could not read Username for 'https://github.com'`, although `gh auth status` said signed in.
- **Your own git setup still goes first.** Only when git finds no login for the https address, Dispatch tries one more time and asks the GitHub CLI for that host.
- **No login is stored.** The second try gives git the login for that one command. Nothing is written to your git configuration or to your keychain.

## What was wrong

"Signed in with `gh`" does not always give git a login for https. When ssh is the git protocol of the GitHub CLI, `gh auth login` sets no credential helper, so git has no login for an https address. The hint under the error said to sign in with `gh auth login`, which the person already had done.

## If you saw this error

Update, then press "Check now" on the marketplace row. An address in the ssh form (`git@github.com:org/repo.git`) worked before and still works.

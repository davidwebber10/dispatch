# Dispatch v2.22.0 — the thread tells you how it ended

## The changes

**Status cards.** A thread's `report_status` now renders as a real card in every
state — green "Done", amber "Waiting on you", blue "Blocked" — instead of a
muted one-liner you could scroll past. An unknown state shows its raw name
rather than borrowing "Done".

**Grok threads pair their tools again.** Reopening a finished Grok thread showed
every tool call as "running…" forever: the REST history parser dropped the tool
ids, and Grok interleaves thinking between a call and its result, so the
adjacency fallback paired nothing. The parser now carries the ids through.

**Quieter thinking rows.** A collapsed thinking row is now the brain icon plus a
dim one-line preview of the thought (width-capped, backticks stripped). The
"Thinking" label only appears while the row is open.

**Model name in the composer footer.** Pretty mode shows the short model name —
"Opus 4.6 · ▬ 11% context" — left of the context bar, in the same tappable
indicator.

**Grok in analytics.** Grok turns charted as "unknown": its usage frames never
named a model. The translator now stamps the real ACP model id on them.
Historical rows recorded before this stay "unknown".

**The update rain.** The glass card over the pixel rain is actually glass now
(less fill, less blur — 22px of blur was averaging the rain into a wash), and
your cursor pops raindrops into little spark bursts on contact.

## Updating

**Web + daemon** — the daemon restart applies the core fixes (Grok tool
pairing, analytics model); refresh the browser for the rest.

# Dispatch v3.14.0 — usage rings, banked resets, one sheet everywhere

## The change

**Usage, at a glance.** Tap the usage chip for one card per tool (Claude, Codex):

- A ring shows what is **left** of a limit and empties as you use it; the big number in it says
  how much is **used**. Green, then yellow from 50% used, then red at your warning level, with a
  small tick where each colour starts. It sweeps into place when the sheet opens.
- A tool with several limits lists them all; tap one to put it in the ring.
- Each limit shows when it resets and, once there is enough history, an estimate: "out ~Sat
  8:14 AM" or "lasts to reset" at your recent pace (marked EST).

**Figures without a Pretty thread.** Codex is asked directly every few minutes. For Claude, when
the figures are more than 5 minutes old and you have been active in the last 30, Dispatch runs one
tiny background turn on Haiku (about 6 tokens) to read them. A Pretty thread in use keeps them
fresh by itself, so then nothing extra runs.

**Banked Codex resets.** The Codex card shows how many resets you have banked and when each one
expires (one about to expire is yellow). "Use one" spends the one that expires soonest, after you
confirm.

**Previews** open in the slide-up sheet, show images as pictures, show each item's date and
time, and keep the unviewed dot until you close the sheet.

**Threads view** has Active and Archived tabs; restore an archived thread from there.

**Phone**

- Going from a thread to Chat and back to Threads returns you to that thread.
- Every menu and sheet now uses the same slide-up sheet: the + menu, Keys, Slash commands, the
  thread ⋯ menu, Settings' add forms and the Previews file reader.
- The composer puts your text on its own line once you type. The mic says when dictation is not
  set up, with a link to Settings → Transcription. The send key uses your theme colour.
- The header buttons are one size, and the "Needs you" card matches the cards around it.
- A daemon restart no longer moves threads to the top of the list.

## Known limits

Spending a banked reset has not been tried against a real account yet.

## Updating

Run `dispatch update`, then reload the app on each phone. There is no database migration.

# Dispatch v4.2.4 — Coach reviews show real progress

## What was wrong

- A Coach review (a thread, a project, your week, or the 30-day look back) reads each thread in
  parts, one model call per part. The screen only moved when a whole thread was done, so a long
  first thread left it on "Reading 0 of 27 threads…" for many minutes. It looked stuck; it was not.

## The change

- The review now shows a progress bar by parts, the thread it is reading with "part 4 of 12 ·
  thread 3 of 27", the time so far, and about how long is left (after the first two parts).
- The Coach tab in a thread's right column shows a running review in a short strip with Open.
- Skipped and empty threads come off the total at once.

## Updating

The bundled Coach plugin only. Run `dispatch update` (or `./bin/dispatch update` from the
repository folder), then reload the app. A review that is running during the update stops; use
Run again.

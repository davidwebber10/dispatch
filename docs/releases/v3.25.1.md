# Dispatch v3.25.1: a way out of the Automations pane

## The change

- **The Automations pane has a close button.** An X at the right end of the pane's header closes
  it and brings back the tabs you had open, with the same tab active. Before, the only way out was
  to pick a thread or the control plane in the sidebar.
- **Escape closes it too.** In a run's detail view, the first Escape goes back to the run list and
  the second closes the pane. Escape is ignored while you type in a field, edit a schedule, or
  have a menu open.
- **Focus lands somewhere sensible.** After closing, keyboard focus returns to the tab you were on,
  or to the Automations button in the sidebar.
- **Escape in the sidebar's Sort menu closes only the menu**, not the pane behind it.

The phone is unchanged: it already has a Back button.

## Known gaps

- Checked by unit tests only, not yet in a browser or on the phone.
- A terminal tab may keep focus after the pane closes.

## Updating

Web client only. Run `dispatch update` (or `./bin/dispatch update` from the repository folder),
then reload the app.

# v2.26.0 — the design pass

A Claude Design project, implemented and then tuned live against Dispatch on a
phone: the three settings pages reorganized, and the Pretty chat re-skinned.

## Settings — Integrations, Secrets, Tools

Same functionality, better organization:

- Mono section labels with summary lines (`12 servers · 10 on`), grouped rows
  with hairline rules and count + hint headers.
- **Integrations**: ACTIVE/OFF groups, REMOTE/LOCAL transport chips, accent On
  buttons, red-hover remove. Add-a-server keeps the advanced local-command form.
- **Secrets**: connected chip + Re-sync + Disconnect, read-only toggle row,
  filter bar (search, Reveal all values), Name/Value grid with masked values,
  copy-with-✓, and a read-only banner.
- **Tools**: search + All/Ready/Needs-auth segments, ready/needs-auth/missing
  groups with status dots, kind chips, docs links.
- Mobile: the same pages reflowed, with bottom-sheet add flows.

## Pretty chat

- **Turns**: YOU-labeled accent bubbles; consecutive sends group under one
  label (split only when something rendered between); hairline separators
  between exchanges.
- **Tool calls**: full-bleed mono strips — glyph · name · args · meta — with
  the chevron on the text rail, no indent. Consecutive calls fuse into one
  strip; edit runs aggregate a green `+33 −9` diff stat. JSON inputs render
  as `key: value · …` summaries instead of raw JSON.
- **Insights**: accent-railed, clamped to two lines, tap to expand.
- **Status**: NEEDS YOU (coral) and DONE (green) cards with the dot +
  letterspaced-label language; the AskUserQuestion card matches, with inline
  answers and "or reply below".
- **Answered questions**: fixed — single-select answers whose label contains
  a comma ("No, visual redesign only") now show as selected; free-text Other
  answers display verbatim instead of vanishing.
- **Images**: markdown-embedded images open the lightbox (they did nothing);
  double-tap zoom joins pinch; the lightbox renders via a portal so it can't
  be trapped invisible by the mobile shell's transforms. **Core fix**: the
  transcript parser dropped image blocks on normal user turns, so a sent
  screenshot vanished from rebuilt history entirely.
- **Composer**: the familiar layout with an ↑ send key — 44px on mobile, and
  the iPhone keyboard's return key is now the blue Send action.

## Updating

Core + web: `dispatch update` (pull, rebuild, restart). The transcript image
fix applies to history loaded after the restart.

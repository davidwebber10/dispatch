# Dispatch v4.6.1 — Claude Design tools in Pretty mode

## The change

- **Pretty Claude threads now have the Artifact tools:** `Artifact`, `ArtifactComments` and
  `ArtifactData`. Before, you had to switch a thread to CLI mode to make a design, a deck, a
  dashboard or a page.

## What was wrong

Pretty threads run Claude Code in print mode (`claude -p`). In print mode, Claude Code turns the
Artifact tools off by default. Dispatch now sets `CLAUDE_CODE_ARTIFACT=1` for Pretty Claude threads,
which turns them on again. If you set `CLAUDE_CODE_ARTIFACT` yourself, your value wins.

## Updating

Needs a daemon rebuild and restart: run `dispatch update`. A Pretty thread gets the tools when it
starts or restarts.

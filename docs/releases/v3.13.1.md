# Dispatch v3.13.1 — fixes: list order after an update, rounded corners, send colour

## The change

- **Threads no longer jump to the top after an update.** A thread whose background process
  ended while it was idle (a daemon restart, an idle unload) was counted as just active, so
  after every update the threads with a live Pretty process moved to the top of the list. Only
  a process that ends mid-turn counts now.
- **One set of rounded corners.** Every corner in the app now comes from one scale instead of
  18 slightly different sizes. The composer and the terminal card on a phone now match.
- **The send key is your theme colour** (green by default) instead of white.
- **A dictation error** (for example, microphone access blocked) shows as one line above the
  composer, with Retry and Dismiss, instead of being squeezed inside it.

## Still to check

The fade at the top of the screen on iOS needs the app removed from the Home Screen and added
again; iOS reads the status-bar setting only when the app is added.

## Updating

Run `dispatch update`, then reload the app on each phone. There is no database migration.

# Dispatch v3.18.1 — sheets you can pull closed, a calmer composer

## The change

- **Sheets:** pull the content down when you're at the top of a sheet and the sheet follows your
  finger; let go far enough (or flick) and it closes, as on iOS. A scrolled sheet's title bar now
  stays at the very top, so the list no longer shows through above the handle.
- **Composer:** dictating stays on one line (+, the recording bar, send). Only typing moves your
  text onto its own line, and that change now glides instead of jumping.
- **Threads view:** the Mine · Agents · All filter only appears once an agent has started a thread.

## Updating

Run `dispatch update`, then reload the app on each phone. There is no database migration.

# Dispatch v2.31.0 — honest analytics, a dollar tile, and release authors

## The changes

**Analytics now measures every harness correctly.** An audit against the real
database found every OpenCode turn recorded with zero output tokens: the
recorder was summing OpenCode's context-fill *gauge* as if it were the bill,
and dropping the real per-turn usage that arrives at the turn boundary. The
gauge and the bill are now separate frames, so OpenCode turns record their true
input, output, and cache-read splits. Claude's `<synthetic>` placeholder can no
longer mislabel a turn's model either — 3.5M tokens sat under that fake key.

**Real provider cost is recorded.** OpenCode reports an actual dollar cost per
turn over the wire. A new `usage_turns.cost_usd` column stores it, guarded so a
resumed session can never re-bill its whole history and Claude's
session-cumulative figure is never mistaken for a per-turn delta.

**A new EQUIV API VALUE tile.** The Analytics view now shows what the range's
tokens would cost at API list rates — a notional figure, not a bill. Priced
models value at list rates; unpriced models at their provider-reported cost;
tokens with neither add nothing and badge the tile "partial" instead of
silently understating.

**The history import is gone.** Analytics records live from the moment tracking
started, and that is all. The Import/Remove controls, the importer, and the
`/backfill` routes are removed; any rows an old import left behind are swept at
boot so turn counts stay one unit.

**The update window shows who published each release.** Each entry in the
release-notes panel now carries the publishing GitHub account, with its avatar,
beside the version and date.

## Notes for existing installs

The `cost_usd` column is added by an automatic, additive migration — verified
against a copy of a real database. OpenCode turns recorded before this release
keep their old (output-less) shape; they are the main reason a long "All time"
range shows the "partial" badge on the value tile.

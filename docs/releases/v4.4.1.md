# Dispatch v4.4.1 — A Previews tab per thread, and "This thread" on the usage rings

## At a glance

- **A Previews tab in the right column (desktop).** Next to Details, Files and Coach, a new
  **Previews** tab shows only what the open thread handed you: reports, screenshots, links and
  text. The Previews screen in the rail still shows everything.
- **"This thread" on the usage rings (desktop).** When a thread is open, the ring of the account
  that the thread uses is marked **This thread** in the far-left usage list. The Usage popover
  shows that account first, marked **This account**.

## Details

- The Previews tab marks the thread's new previews as seen when you leave the tab.
- A thread that is pinned to an account marks that account. A thread that is not pinned marks the
  default account of its tool.
- The right-column tabs now take the width of their names, so "Previews" is not cut off.

## Updating

Web and the bundled Previews plugin only. Run `dispatch update` (or `./bin/dispatch update` from
the repository folder), then reload the app.

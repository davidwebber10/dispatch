# Dispatch v4.6.2 — clear answers in the threads you start

## The change

- **Threads that you start no longer have the `report_status` tool or its rule.** Before, every turn
  had to end with that tool. The model then often put its real answer in its thinking, called the
  tool, and wrote one short closing line. You saw a folded "Thinking" row and a "Needs you" box, but
  not the answer.
- **Threads that another thread starts keep it.** These are Chat threads, Control Plane agents,
  coordinators and scheduled roles. The thread that started them reads the declared end state.
- **The status of your own threads still works.** Dispatch reads it from the end of the turn: a
  question means "Needs you", and other answers mean "done".
- The status-quality report counts only threads that have the tool.

## Updating

Needs a daemon rebuild and restart: run `dispatch update`. A thread gets the change when it starts
or restarts.

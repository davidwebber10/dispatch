# Dispatch v2.47.1 — inline Codex terminals on mobile

## The change

New and resumed Codex terminal threads now use the inline TUI, preserving terminal
scrollback for easier navigation on mobile.

## What was wrong

Codex used its fullscreen alternate screen, which made terminal threads awkward to
use on a phone. Dispatch now passes `--no-alt-screen` when launching or resuming a
Codex terminal thread.

## Updating

Run `dispatch update` to rebuild and restart the daemon. The change applies when a
Codex terminal thread is next launched or resumed.

# Dispatch v4.12.1: the text box keeps the focus after a dictation

## The change

- **After a dictation, the text box has the focus again, with the cursor at the end of the text.** You can type on at once. Before, the box lost the focus when the text came back, and you had to click into it again.
- **A field you moved to keeps the focus.** If you open the command palette or click another box while the text is on its way, the focus stays there.
- **The way back from a failed dictation does the same.** A Retry that works, Insert from Recordings and Dismiss all put the focus back in the box.
- **On a desktop only.** On a phone a focus opens the keyboard, so nothing changes there.
- **Removing a plugin marketplace while Dispatch pulls it no longer fails.** Before, Remove could show an error now and then.

## Updating

Run `dispatch update`, then reload the app.

# Dispatch v2.32.0 — the FILES shelf folds away, or leaves entirely

## The changes

**The FILES shelf opens and closes.** A chevron sits directly right of the FILES
label in every project card. Click it and the shelf folds away; click it again
and it comes back exactly as it was. The state is per project and it persists,
so a shelf you closed stays closed across a refresh — re-closing it on every
reload would have made the control pointless.

**A setting removes pinned files altogether.** Settings → SIDEBAR now carries a
**Pinned files** toggle. Turn it off and the FILES shelf disappears from every
project card — header, chevron and rows. It is for anyone who opens files from
the file browser and never wanted the pinned list in the sidebar. Pinning still
works and **Browse Files** is untouched; the setting only governs the shelf.

Both default to today's behaviour, so an install that touches neither control
looks exactly as it did before.

## Notes for existing installs

This release is web-only. A **browser refresh** picks it up once the daemon
serves the new bundle; no rebuild of a running thread is required beyond the
usual `dispatch update`.

The release guard also grew teeth in this cycle: `dispatch release` now refuses
when any of the four `package.json` files lags the version being released, and
names each one. v2.31.0 shipped with only the root file bumped, which let a
correctly-applied update go on announcing itself forever.

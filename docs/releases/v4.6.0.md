# Dispatch v4.6.0 — Previews is now the Inbox, with a card for each kind

## At a glance

- **Previews is now the Inbox.** Threads say "I put it in your Inbox". The icon is a tray.
- **A card for each kind of item.** A small label with an icon and a colour tells the kinds apart.
- **Images open faster,** most of all on a phone away from home Wi-Fi.
- **Restart once** after you update: the daemon changed.

## The kinds

- **Command:** one row for each command, with a `$` and its own **Copy** button. **Copy all** when
  there are several. It can show the folder in which to run the commands.
- **Link:** the site name, the full address, **Open** and **Copy**.
- **Code:** a label with the language, and **Copy**.
- **Secret:** hidden as •••• and the last 4 characters, with **Reveal** and **Copy**. It never
  shows in a title, a list or an alert. Dispatch removes it 24 hours after the thread sent it.
- **Steps:** a numbered list. A step with a command has its own **Copy**.
- **Diff:** added lines in green, removed lines in red.
- **Table:** CSV or JSON as a small table, with the first 50 rows.
- Documents, text, images and files work as before. They also get a label.

## Faster images

- Dispatch keeps its own copy of each file that a thread sends. That copy never changes, so your
  phone keeps it and does not ask for it again.
- The viewer shows the small copy at once, then a copy sized for the screen (about 200 KB in place
  of a 2–4 MB screenshot). **Original** opens the full file.
- An item no longer breaks when the thread changes or deletes its file later.

## For plugin authors

- The shared file viewer takes `placeholderSrc` and `displaySrc` for each image.
- Plugin files keep a copy made at post time and are served with a long cache.
- A right-column tab can have a `badge` (v4.5.2).

## Updating

Run `dispatch update`. The daemon restarts once (a database migration adds the file copy). Then
reload the app. Threads that are already running get the new tool text when they restart.

# Dispatch v2.34.0 — the Control Plane catches up

## The change

The Control Plane had drifted behind the Pretty chat (43 render commits vs 11 since
mid-July). This release closes the gap in both directions.

**The stream now shows the coordinator's actual work.** Its adapter used to render four
message kinds and silently drop the rest — built when "the Overseer does no tool work."
Now, with the same components the agent chat uses:

- Generic tool calls render as machinery strips: tool rows, same-tool ×N collapse with
  the running shimmer, orphan results.
- `report_status` renders as the DONE / BLOCKED / NEEDS YOU card instead of vanishing.
- Thinking blocks (collapsed with a preview), turn footers (cost · tokens · duration ·
  turns), and background-task notices all render.

**Coordinator control and honesty:**

- The send key morphs into a graceful **Stop** over an empty composer while a turn runs
  (the turn ends, the thread lives). Send is disabled-grey when there is nothing to send.
- The stream shows the compaction bar during a native `/compact`, so a minutes-long
  compaction no longer reads as a dead session.
- The context meter uses the wire-true window instead of guessing from the model name,
  and the directive box tells mobile keyboards to say Send.

**Three back-ports the other way** (the Control Plane was ahead): the agent chat gains
the paint-settle gate (opening a long thread lands at the bottom with zero visible
catch-up crawl), the IME guard (Enter mid-CJK-composition commits the candidate, not the
turn), and the OS-aware ⌘/Ctrl+↵ send hint.

## Under the hood

- New shared `MachineryStrip` (tabs/chat) reusing `ToolCall`/`ToolGroup`/`MachineryBlock`;
  `Thinking`/`ResultFooter` exported from ChatView for cross-surface use.
- `convItemsToStream` emits five new StreamMessage kinds; `Stream.tsx` renders them.
- `contextWindow` plumbed through the coordinator context-info sync.
- `StickToEndOnLoad` gains the quiet-window reveal latch (180ms) behind a
  visibility-gated scroller.
- Tests: 22 new across adapter, strip, stream, composer, store, and ChatView.

## Updating

**Web-only** — after `dispatch update`, a browser refresh is enough; nothing in core
changed in this release.

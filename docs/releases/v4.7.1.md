# Dispatch v4.7.1 — fix the hosted image release check

## The change

- **The hosted image release check works.** The release workflow now builds the proved image with
  the same labels as the image it pushes, so the check that compares the two can pass.

## What was wrong

The v4.7.0 release did not publish a verified hosted image. The pushed image had three labels
(source, revision, version) that the proved image did not have. The check compares the full image
configuration, labels included, so it failed, and no build attestation was made.

## Updating

Nothing changes on a local install. This release only affects the hosted image that the release
workflow builds.

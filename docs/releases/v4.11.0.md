# Dispatch v4.11.0 — a text scale for the whole app

## The change

- **New setting: Settings > Appearance > Text scale.** A slider from 75% to 150%, in steps of 5%.
  The button next to it puts it back to 100%. The text changes while you move the slider.
- **It is per device.** A phone and a computer can use different scales. The setting is kept in the
  browser of that device.
- **All text follows it:** the sidebar, threads in Pretty and in CLI mode, Chat, the Control Plane,
  Settings, files, Analytics charts, the Inbox and the Coach.
- **The terminal follows it too.** Its size is the Terminal size times the scale. The sidebar name
  sizes work the same way: the steppers set the base size, and the scale multiplies it.
- **Spacing, icons and panel widths do not change.** Only text grows or shrinks.
- **Nothing changes at 100%.** Every size is the same pixel value as before.
- **On a phone, a text box never goes under 16px**, at any scale. Below that size iOS zooms the page
  when you tap the box.

## Known limits at large scales

Panels with a fixed width do not grow with the text. At 150%:

- **Phone:** the Settings back link and the page title touch. The terminal's message placeholder is
  cut (also at 125%).
- **Desktop:** the sidebar's AUTOMATIONS tab is cut, and "Open Control Plane" wraps to two lines.
  You can make the sidebar wider.
- **Usage cards:** a long account name can leave the card.

## For plugin authors

- Write font sizes in `rem`, not `px`: `fontSize: '0.8125rem'` is 13px at 100% and follows the
  scale. `docs/plugins.md` has the details. A new plugin from the template already does this.
- The Inbox plugin is now 1.2.1.

## Under the hood

- Each font size is a CSS variable in `rem` (`--fs-13`), and the scale sets the root font size.
- A test now fails when new code sets a font size in fixed pixels, so the scale stays complete.

## Updating

Run `dispatch update`, then reload the app.

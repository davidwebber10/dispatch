# Dispatch v2.23.0 — the open-model harness

## The changes

**OpenCode joins the harness list.** A fourth card in the New Thread picker,
next to Claude Code, Codex, and Grok. It runs the leading open-weights models
through OpenRouter: GLM-5.2 (default), Kimi K3, DeepSeek V4 Pro, Qwen3.7 Max,
and MiniMax M3. Pretty-only, on the same ACP transport as Grok — streaming
tools, turn boundaries, status reporting, and real per-turn dollar cost from
the wire. The context bar shows each model's true window, not a guess.

**Install and key flow in the modal.** Not installed? The card offers the
install, like Grok. No key? Paste an OpenRouter key once — it saves to Doppler
and injects at spawn. It never lands in a file or in this repo.

**A Harnesses section in Settings.** Per-harness defaults that the New Thread
modal picks up: default model for every harness, default mode for Claude Code
and Codex, and the Doppler secret name that holds the OpenCode key (with a
live present/missing check and a replace field). Rename or rotate the secret
and the next spawn uses it — no restart.

## Updating

**Web + daemon** — the daemon restart brings the new harness and settings API;
refresh the browser for the picker and Settings section.
